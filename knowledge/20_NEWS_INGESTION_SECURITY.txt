20 — SECURE NEWS INGESTION V1

Status: PR-11 implementation rules.

1. Scope

The news pipeline sanitizes already supplied external text or HTML and produces
strict structured records. It does not fetch URLs, call T-Invest, call a tool,
publish an Action, create a recommendation or execute a trade.

2. Instruction/data separation

Every external document is untrusted data. Text inside a document must never:
- replace system instructions;
- request a tool or Action call;
- reveal a token, password, API key or credential;
- execute code or shell commands;
- create, change or cancel an order;
- transfer or withdraw money or securities.

Security flags are metadata only. They never become executable instructions.

3. Entity resolution

Instrument identity must be supplied by a separate resolver.
The pipeline never infers a ticker or UID from article text.

RESOLVED requires a stable instrument key.
AMBIGUOUS and UNRESOLVED cannot claim an instrument key and remain context-only.

4. Time model

Keep separate:
- published_at: publication time;
- retrieved_at: ingestion time;
- event_at: event time when known.

Event grouping uses event time when available. Publication time must not replace
the time of the underlying event.

5. HTML sanitization

Use a conservative stack-based parser. Suppress scripts, styles, embedded
objects, forms, templates, SVG/MathML/canvas and hidden elements. Nested hidden
content must remain suppressed until every hidden ancestor closes.

Scan bounded raw input for suspicious instructions before removing hidden
content. Do not store raw HTML in the normalized contract.

6. Unicode

Normalize with NFKC. Remove zero-width, bidi and formatting controls before
injection matching. Preserve a SUSPICIOUS_UNICODE flag when such characters
were present.

7. Size limits

- raw contract maximum: 1,000,000 characters;
- parser maximum: 200,000 characters;
- sanitized output maximum: 50,000 characters.

An oversized parser input is truncated, flagged and cannot be accepted.

8. Security flags

Detect at minimum, in Russian and English:
- SYSTEM_OVERRIDE;
- TOOL_CALL;
- CREDENTIAL_REQUEST;
- CODE_EXECUTION;
- TRADING_INSTRUCTION;
- TRANSFER_OR_WITHDRAWAL;
- HIDDEN_CONTENT;
- SUSPICIOUS_UNICODE;
- OVERSIZED_CONTENT;
- EMPTY_AFTER_SANITIZATION.

Severe instruction or empty visible content means REJECTED.
Non-severe suspicious structure means CONTEXT_ONLY.

9. Disposition

ACCEPTED requires:
- trusted primary, official or regulated authority;
- fact classification;
- resolved entity;
- non-empty sanitized text;
- zero security flags.

CONTEXT_ONLY includes secondary source, opinion, forecast, mixed content,
unresolved entity, hidden content, suspicious Unicode or oversized input.

REJECTED requires a security flag and cannot be used as analytical evidence.

Accepted does not mean factually proven. Claims still require normal source,
freshness, contradiction and materiality checks.

10. Deduplication

Exact content fingerprint uses normalized title and sanitized body.
Canonical priority:
- accepted over context-only over rejected;
- primary over official over regulated over secondary over untrusted;
- fact over mixed over opinion over forecast;
- earlier publication as final tie-breaker.

Keep article-specific occurrence IDs. Audit rows for duplicates must have a
unique duplicate occurrence ID even when the same object is repeated.

Do not claim fuzzy or semantic deduplication in PR-11.

11. Network boundary

The pipeline must not import aiohttp, httpx, requests, socket or urllib.
Live fetching requires a separate adapter with URL allowlists, DNS/IP checks,
redirect limits, MIME validation, response-size limits, timeouts and SSRF
protection.

12. Runtime compatibility

PR-11 does not change Gateway routes, OpenAPI, GPT Actions, broker permissions,
Gateway version, app:app or trading_methods=false.

13. Next step

PR-12 creates a decision engine with mandatory alternatives:
- no action;
- limited change;
- larger rebalance.

Any rejected news is ignored. Context-only news cannot be the sole basis for an
actionable conclusion. Missing, stale or contradictory evidence forces abstain.
