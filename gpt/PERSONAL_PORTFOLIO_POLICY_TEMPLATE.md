# PERSONAL_PORTFOLIO_POLICY — шаблон владельца

Этот файл предназначен для заполнения владельцем и загрузки в Knowledge существующего Custom GPT.

Не указывать:

- токены и API-ключи;
- полный номер брокерского счёта;
- паспортные, банковские и платёжные данные;
- логины и пароли.

После заполнения переименовать отображаемое название в `PERSONAL_PORTFOLIO_POLICY`.

## 1. Цели

- Главная цель: `[сохранение капитала / умеренный рост / доход / смешанная цель]`
- Дополнительная цель: `[текст]`
- Приоритет сохранения капитала: `[низкий / средний / высокий]`
- Защита от инфляции: `[да / нет / комментарий]`

## 2. Горизонт

- Основной горизонт: `[месяцы/годы]`
- Планируемая дата крупного изъятия: `[нет / дата / период]`
- Допустимы ли временные просадки до горизонта: `[да / нет / условия]`

## 3. Риск

- Максимально допустимая просадка портфеля: `[%]`
- Отношение к волатильности: `[низкая / умеренная / высокая]`
- Допустимая доля высокорисковых активов: `[%]`
- Допустима ли потеря части капитала ради роста: `[нет / ограниченно / да, до %]`

## 4. Ликвидность и резерв

- Минимальный денежный резерв в портфеле: `[% или сумма]`

- Минимальная доля высоколиквидных инструментов: `[%]`
- Максимальный срок блокировки денег: `[срок]`

- Облигации: `[минимум % — максимум %]`
- Фонды денежного рынка/короткие инструменты: `[минимум % — максимум %]`
- Другие фонды: `[минимум % — максимум %]`
- Валюта/валютные инструменты: `[минимум % — максимум %]`
- Драгоценные металлы через доступные инструменты: `[минимум % — максимум %]`
- Свободные деньги: `[минимум % — максимум %]`

## 14. Правило при недостатке данных

По умолчанию:

> Если данных недостаточно, Omni-CIO не должен придумывать точную рекомендацию. Он обязан показать, каких данных не хватает, и предложить безопасный следующий шаг.
