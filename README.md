# Analyst AI — Android и Timeweb backend

Kotlin / Jetpack Compose. Android 13+ (minSdk 33), compileSdk/targetSdk 36.
Версия 0.5.0 / versionCode 21. Открывайте корень проекта в Android Studio.

## Установка и совместимость

Производственный applicationId: `ru.omnicio.app`. Тестовая линия: `ru.omnicio.app.debug`.
Распространяемый `preview` оптимизирован, не содержит отладчика и debug-only компонентов,
подписан прежним тестовым ключом. Это не магазинная производственная подпись.
Для обновления без удаления данных должны совпадать package и сертификат подписи.
Пользователь подтвердил установку предыдущей 0.4.2 на телефоне.

Перед публикацией проверяются подпись, закреплённый сертификат, DEX, ZIP/ELF,
отсутствие testOnly/debug-флага, установка с нуля и запуск на Android 13/16.
В PR проверяется обновление с оригинального опубликованного APK 0.4.2.
Загруженный APK скачивается обратно для сверки SHA-256; отчёт `apk-verification.json`.
Успешный тест эмулятора не равен полному испытанию физического Samsung.

## Интерфейс 0.5.0

- Сохранённые светлая, чёрно-серая и системная темы; контрастные системные панели.
- Равные горизонтальные вкладки профиля; работают Оформление, Безопасность и О приложении.
- Пять нижних вкладок: Портфель, Что купить, Пульс, Чат, Профиль.
- Автоматическое обновление портфеля через 15 секунд после завершения успешного запроса,
  только пока приложение на переднем плане. При сбоях интервал увеличивается до 120 секунд.
- При RUB → USD → EUR сохраняются карточки и прокрутка; до ответа видна предыдущая
  валюта, затем меняются суммы. Валюту общей оценки рассчитывает T-Invest API.
- Время успешного получения данных и сообщение о сбое; сохранённые значения не выдаются
  за новые. Нет постоянной кнопки ручного обновления и нет LLM для пересчёта чисел.

## Портфель и данные

`/tinvest/dashboard`: GetAccounts, GetPortfolio, GetPositions. Все доступные открытые
счета, позиции и денежные остатки; отдельно виртуальные и неоценённые заблокированные
бумаги. Карточка инструмента: количество в штуках, цена, средняя цена, НКД, результат,
блокировка, ISIN и биржа, когда соответствующие поля доступны. Названия постепенно
уточняются через GetInstrumentBy и кешируются без дополнительных LLM-вызовов.

Для выбранного счёта:
- Операции GetOperationsByCursor с подгрузкой страниц, категориями и календарём.
  На экране не более 10 000 операций; дальше требуется сузить период.
- Активные заявки, стоп-заявки и ограничения вывода: GetOrders, GetStopOrders,
  GetWithdrawLimits. Недоступность раздела не маскируется пустым списком.
- Аналитика выполненных операций по исходным валютам. Лимит расчёта 20 страниц
  по 1000 операций; неполный расчёт отмечается. Оборот не называется прибылью.
- История стоимости по реальным снимкам Analyst AI: интервалы 5 минут/час/день;
  частые точки хранятся 7 дней, часовые 90 дней, дневные без удаления.
  Существующий серверный планировщик сохраняет уже запрошенную RUB-оценку даже
  без запуска модели. История USD/EUR пополняется при запросах соответствующей валюты.
- Периоды День, Месяц, 6/12 месяцев, текущий год, Всё время и собственные даты.
- Календарь опубликованных дивидендов/купонов по текущим бумагам: GetDividends,
  GetBondCoupons. Неизвестная дата или неподтверждённое право на выплату отмечаются;
  оценка по текущему количеству не гарантирует поступление и не прогнозирует налог.

Диаграмма классов активов использует оценки брокера в выбранной валюте. Диаграммы
компаний/отраслей/валют строятся только при наличии сопоставимых положительных
стоимостей всех показанных позиций; иначе видна разбивка и причина отсутствия общего
графика. Неизвестное значение показано как «—», а не выдуманный ноль.

## Безопасность

Telegram OIDC с PKCE и возвратом `analystai://auth`. Серверный сеанс 30 дней,
Android хранит сеанс зашифрованным. После удаления приложения нужен новый вход.
T-Invest read-only токен проверяется GetAccounts и хранится Fernet-шифротекстом
на сервере Timeweb, привязанным к аккаунту; в APK не включается и обратно не выдаётся.
Все новые маршруты требуют действующего сеанса и проверки принадлежности счёта.
Кеш пользовательских данных разделён по пользователю и версии зашифрованного токена.
TLS-проверка включена, редиректы при передаче токена запрещены.
Запрет снимков экрана включается только пользователем. Нет автоматических сделок,
отмены поручений, пополнений или выводов через Analyst AI.

`TIMEWEB_CLOUD_TOKEN` управляет инфраструктурой; `TIMEWEB_AI_TOKEN` вызывает модели.
Для LLM также нужны точные `AI_MODEL_FAST`, `AI_MODEL_STANDARD`, `AI_MODEL_PREMIUM`.
Без ключа работают только алгоритмические проверки. Наличие кода не доказывает
живую интеграцию моделей. Ключи не коммитить, не включать в APK и не выводить в логи.
Telegram Redirect URI: `https://94.198.220.228.sslip.io/auth/telegram/callback`.

## Что ещё не завершено

- Нет полной реконструкции исторической стоимости до начала сбора, полной доходности
  за произвольный период с учётом всех денежных потоков и точного повторения внутренних
  графиков Т-Банка. Получить историю операций не значит получить готовый график NAV.
- Не все поля и отчёты T-Invest API выведены на экраны. Нет полного архива закрытых счетов,
  единой issuer/asset-группировки, полной оценки производных инструментов и исторической
  конвертации многовалютной структуры. «Все данные API» не заявляются готовыми.
- Пока периодический опрос, не PortfolioStream/PositionsStream/OperationsStream.
- Календарь выплат не восстанавливает право по уже проданным после реестра бумагам.
- ИИ: реальные Gateway-модели, мировой архив новостей/отчётности/макроданных,
  полноценный календарь бирж, персональный отбор конкретных доступных инструментов,
  оценка пригодности/ликвидности/ограничений, денежные бюджеты в рублях и сверка биллинга,
  устойчивая очередь/аварийные провайдеры и push/Telegram ещё требуют завершения.
- Производственная подпись, Native Telegram SDK и публикация в магазине не выполнены.

## Проверки

`py -3 -m unittest discover -s backend/tests -p "test_*.py" -v`

`py -3 -m unittest discover -s .github/scripts/tests -p "test_*.py" -v`

`gradlew.bat :app:lintDebug :app:lintPreview :app:assembleDebug :app:assembleRelease :app:assemblePreview`

CI проверяет профиль и темы на изолированном эмуляторе через синтетическую Activity
из src/debug. Она не входит в распространяемый preview и не обходит реальную авторизацию.
Проверяются светлая/тёмная/системная тема, сохранение выбора после перезапуска,
диалоги и горизонтальность Инфо при увеличенном шрифте.
Все применимые проверки актуального SHA, включая Sonar, должны пройти до слияния.
Настройки качества нельзя ослаблять ради зелёного статуса.
