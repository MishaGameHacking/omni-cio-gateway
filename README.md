# Analyst AI — Android и Timeweb backend

Kotlin / Jetpack Compose; Android 13+ (API 33), compileSdk/targetSdk 36.
Откройте корень проекта в Android Studio. Сборка: `gradlew` / `gradlew.bat`.

## Совместимость

Release package: `ru.omnicio.app`. Тестовая линия: `ru.omnicio.app.debug`.
Для обновления без удаления данных должны совпадать package и сертификат подписи.
Версия 0.4.2 / versionCode 20: компактный `preview` без отладчика и debug-only tooling,
подписанный прежним тестовым ключом. Это не производственная подпись для магазина.
Пакет, минимальная версия Android и серверные данные не меняются.

## Установка APK

Перед публикацией проверяются подпись, закреплённый сертификат, DEX, ZIP/ELF,
отсутствие testOnly и debug-флага, установка с нуля и запуск на Android 13/16.
В PR также проверяется обновление с опубликованной 0.4.1. После загрузки в GitHub
APK скачивается обратно для сверки SHA-256. Отчёт: `apk-verification.json` в релизе.

Исходная 0.4.1 уже успешно установлена и запущена на чистом эмуляторе Android 13.
Это не воспроизводит отказ на конкретном Samsung. Не выдавать неподтверждённую
причину за найденную: для отказа на телефоне нужны модель, Android/One UI и код
INSTALL_FAILED. Подробности проверки: `docs/APK_INSTALLATION.md`.

## Что реализовано

- Telegram OIDC с PKCE, возврат `analystai://auth` и зашифрованное сохранение
  сессии Android. Серверная сессия действует 30 дней; это не бессрочный вход.
- Проверка пользовательского read-only T-Invest токена через GetAccounts;
  зашифрованное хранение Fernet на сервере, без включения токена в APK.
- Реальная загрузка счетов, портфеля и денежных позиций через T-Invest.
  Нажатие на общую стоимость меняет RUB → USD → EUR; валюту рассчитывает API.
- Пять вкладок: Портфель, Что купить, Пульс, Чат, Профиль.
- Серверный планировщик проверок, снимки портфеля, профиль риска,
  сохраняемая лента карточек, отметки прочтения, подбор направлений по классам активов.
- Правила значимости до LLM, fast/standard/premium, лимиты числа попыток,
  структурированный ответ и проверка идентификаторов источников.
- Без ключа модели работают только алгоритмические проверки, не LLM.
  Нет свободного пользовательского чата с моделью и нет автоматических сделок.

## Исправления 0.4.1, сохранённые в 0.4.2

- Остановка планировщика не скрывает отмену вызывающей задачи и ошибки фоновой задачи.
- Ручное обновление не изображает сделку и не обходит фильтр существенных изменений.
- Концентрация проверяется по позиции, объединённой по счетам, а не по целому
  классу активов. Несопоставимые валюты не складываются. Денежная позиция
  не выдаётся за опасную концентрацию ценной бумаги.
- Попытка платного анализа резервируется атомарно до запроса; сетевые ошибки
  и невалидные ответы не создают бесплатных повторов поверх дневного лимита.
- Критические алгоритмические сообщения сохраняются и при нулевом бюджете моделей.
- Сумма предложенных направлений не превышает доступную долю денег за вычетом резерва.
- Пустой TIMEWEB_AI_BASE_URL использует документированный адрес Gateway.
- Обновлены PyJWT и cryptography; добавлены регрессионные тесты.

## Подключение и безопасность

Backend размещается на Timeweb. Cloud-токен управления инфраструктурой
`TIMEWEB_CLOUD_TOKEN` и ключ вызова моделей `TIMEWEB_AI_TOKEN` — разные настройки.
Для LLM нужны `TIMEWEB_AI_TOKEN`, `AI_MODEL_FAST`, `AI_MODEL_STANDARD`,
`AI_MODEL_PREMIUM`. `TIMEWEB_AI_BASE_URL` по умолчанию: `https://api.timeweb.ai/v1`.
Ключи не коммитить, не включать в APK и не выводить в логи.
Наличие конфигурации само по себе не доказывает успешный вызов провайдера.

Telegram Redirect URI:
`https://94.198.220.228.sslip.io/auth/telegram/callback`.
При запрете автоматического открытия приложения браузером на callback-странице
есть кнопка «Открыть Analyst AI». Native Telegram SDK пока не подключён.
Скриншоты разрешены по умолчанию; запрет включается пользователем в настройках.
HTTPS-проверка T-Invest включена; дополнительный корневой сертификат используется
только для этого API. `verify=False` запрещён.

## Ограничения, которые ещё требуют разработки

- Реальные модельные запросы зависят от отдельного Gateway-ключа, точных ID моделей,
  проверки доступа, тарифов и испытаний качества; тестовые ответы не являются живой интеграцией.
- Планировщик использует интервалы и окна по Москве, а не полный календарь бирж
  с праздничными днями и отдельными торговыми сессиями.
- Снимки портфеля ограничены последними 60 записями на пользователя; полноценного
  долговременного рыночного архива и заполненной базы инвестиционного мира нет.
- Таблица market_facts подготовлена, но новости, отчётность, корпоративные события
  и макроданные ещё не собираются в неё автоматически и не участвуют в анализе.
- Что купить показывает классы активов, а не проверенные конкретные инструменты.
  Полная оценка пригодности, ликвидности, валют, горизонта и доступности у брокера
  ещё не реализована; текущие пропорции не являются индивидуальным инвестиционным планом.
- Денежный бюджет в рублях, глобальная квота проекта, точная сверка биллинга,
  устойчивая очередь с заданиями и автоматическое резервирование провайдеров ещё нужны.
- Отдельного канала push/Telegram-оповещений, производственной подписи APK,
  публикации в магазине и полного испытания на реальных устройствах ещё нет.

## Проверки

`py -3 -m unittest discover -s backend/tests -p "test_*.py" -v`

`py -3 -m unittest discover -s .github/scripts/tests -p "test_*.py" -v`

`gradlew.bat :app:lintDebug :app:lintPreview :app:assembleDebug :app:assembleRelease :app:assemblePreview`

Полная проверка установки выполняется фиксированными командами `.github/actions/check-apk`
в Android CI и Android APK. `verify_apk.py` и `validate_distribution.py` только проверяют
конкретные файлы сборки и отчёты; они не принимают произвольные пути и не запускают команды.

Все применимые проверки последнего SHA, включая SonarCloud, должны быть успешны
до слияния. Настройки качества нельзя ослаблять ради зелёного статуса.
