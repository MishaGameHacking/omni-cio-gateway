## Что изменилось в 0.10.0

- **Где открыть:** «Портфель → Динамика», затем выбрать счёт, если их несколько.
  Второй путь — открыть конкретный счёт → «Аналитика».
- **Что означает столбец:** последний сохранённый баланс счёта за интервал.
  Группировка по дням, неделям, месяцам или годам зависит от глубины истории.
  Это собственные снимки Analyst AI; котировки OHLC отдельного инструмента здесь не предоставляются.
- **Как смотреть подробности:** нажать на столбец или провести горизонтально.
  Доступны точная сумма, даты, предыдущий/следующий столбец и сброс выбора.
- **Как читать статистику:** изменение стоимости и минимум/максимум берутся
  из полученных снимков. При одном снимке сравнение явно недоступно;
  пропуски не превращаются в нулевой баланс.
- **Движение денег:** пополнения, выводы, купоны и дивиденды выбранного интервала
  получаются из существующего API; прочие операции раскрываются отдельно.
  Сохраняются исходные валюты. Денежные потоки и изменение стоимости не называются прибылью.
- **Совместимость:** добавлена поддержка Android 15 при целевом API 36;
  сохранены package и подпись установленной preview-линии.

## Реальные функции и текущие границы

Работают Telegram-вход с возвратом `analystai://auth`, защищённое хранение сеанса
Android и серверное хранение T‑Invest read-only токена. Токен подключается через
«Профиль → Аккаунт → Подключение T‑API», проверяется запросом GetAccounts,
хранится зашифрованным на сервере и не встраивается в APK.

Из пользовательского T‑Invest API читаются счета, позиции, операции, заявки
и доступный календарь выплат. История стоимости накапливается собственными снимками;
полной реконструкции данных до начала наблюдения нет. Неизвестные значения
и неполные выборки обозначаются явно. Общую валюту оценки рассчитывает API брокера.

Выпущенный подэтап **F11.1** отделил базовое серверное наблюдение от открытого
приложения, версии APK и Android-сеанса. Полный F11 ещё требует расширения охвата,
источников и эксплуатационной проверки. Подробности: [выпуск 0.7.5](docs/releases/0.7.5.md).

Существуют структурированная AI-аналитика, уровни моделей и бюджетные ограничения.
Настройки и фактическая работа платных моделей в рабочей среде требуют отдельного
подтверждения. Полноценный свободный чат **F16 не подключён**.
Новый конструктор стратегии сохраняет **неактивный локальный черновик**;
общий план конкретных сделок, полный каталог и новые инвестиционные алгоритмы
остаются открытыми задачами. [AI-контур](docs/AI_ORCHESTRATION.md) · [Расчёты и ограничения](docs/RISK_REBALANCING.md).

Целевая личная установка рассчитана на владельца и до четырёх приглашённых аккаунтов.
Полноценный список допуска, обновлённый протокол сеансов и их приёмка относятся к F03.
Скриншоты разрешены по умолчанию; запрет включается пользователем в настройках.

Исходный APK 0.9.0 требовал API 36, поэтому на API 35 проверялась чистая установка.
Подпись, сертификат, пакет, версия, DEX, ZIP/ELF и повторное скачивание проверяются
для конкретных байтов; [apk-verification.json](https://github.com/MishaGameHacking/omni-cio-gateway/releases/download/android-preview-0a894dddfa858efe6c7be60aea78935adec84c1b/apk-verification.json)
опубликован рядом с APK. Синтетическая UI Activity находится в `src/debug` и не входит в preview.

Открывайте корень проекта в Android Studio. CI использует JDK 17 и SDK 36.
Основные команды Windows:

```text
py -3 -m pip install -r backend/requirements-dev.txt
py -3 -m pytest backend/tests -q
py -3 -m unittest discover -s .github/scripts/tests -p "test_*.py" -v
gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:lintPreview :app:assembleDebug :app:assembleRelease :app:assemblePreview
```

На Linux/macOS используются `python3` и `./gradlew`. Все применимые проверки
последнего коммита, включая Sonar, должны завершиться успешно до слияния;
эмуляторный процесс описан в [APK_INSTALLATION](docs/APK_INSTALLATION.md).
Секреты хранятся в серверной/CI-конфигурации, не в исходниках и не в APK.
