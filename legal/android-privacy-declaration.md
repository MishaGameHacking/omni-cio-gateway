# OMNICIO Android — декларация данных и приватности для UI-06

Статус: черновик release-candidate 2.5.0 для сверки перед публикацией в RuStore.
Документ описывает только фактически реализованный Android UI-этап и не объявляет функции системного этапа подключёнными.

## Что работает без аккаунта OMNICIO

- Основной local-first путь не требует email, телефона, ФИО, пароля или social login.
- Приложение создаёт случайный локальный installation/profile id.
- UI-06 использует явно помеченные demo/fixture данные для портфеля, обзора, событий помощника и настроек.
- Реальный T-Invest token в UI-06 не запрашивается и не сохраняется.

## Какие данные хранятся локально в UI-06

Текущее приложение сохраняет только локальное UI-состояние через Android SharedPreferences:

- installation/profile id;
- завершённость onboarding;
- скрытие сумм и выбранную валюту отображения;
- выбранное QA/demo-состояние обзора;
- fixture-состояние портфеля и T-Invest connection UI;
- резерв и горизонт цели;
- настройки локальных/быстрых уведомлений;
- локальную версию схемы UI-state.

Эти значения не являются production broker credential или реальным брокерским портфелем.

## Передача данных

В Android UI-06 нет пользовательского сетевого пути для отправки персонального портфеля на сервер OMNICIO.
В манифесте текущего Android UI-кандидата не запрашивается INTERNET permission.

Экспорт локального fixture-состояния выполняется только по явному действию пользователя через системный Android share chooser.
Экспорт не включает broker credential; UI-этап не содержит реального T-Invest token.

## Разрешения Android

UI-06 объявляет `POST_NOTIFICATIONS` для Android 13+.
Разрешение запрашивается только из экрана настроек по действию пользователя.
Отказ в разрешении не блокирует локальный портфель и остальные локальные UI-функции.

## Deep links

Приложение поддерживает внутреннюю custom-scheme навигацию `omnicio://` для Overview, Portfolio, Position, Assistant и Settings.
Deep link не является авторизацией и не должен содержать секреты.

## Скриншоты экрана

На текущих demo/UI-экранах FLAG_SECURE не включён: UI-06 не отображает реальный broker token или иной секрет.
Это сохраняет совместимость со средствами доступности и пользовательским захватом экрана.
Если на системном этапе появится поверхность с секретом, политика скриншотов должна быть пересмотрена именно для этой поверхности.

## Удаление и экспорт

Пользователь может удалить локальный fixture-портфель из настроек.
Удаление также очищает fixture-состояние broker connection/credential.
Demo-fixture можно восстановить отдельно; это не восстановление реального брокерского портфеля.

## Что пока не подключено

UI-06 не заявляет подключёнными:

- реальный read-only T-Invest transport;
- production secure broker credential storage;
- server-side хранение персонального портфеля;
- RuStore Pay и покупку подписки;
- production push transport;
- пользовательский свободный AI chat;
- автоматическую отправку брокерских заявок или переводов.

Перед фактической публикацией декларация сверяется с release APK/AAB, manifest permissions и реальным runtime behavior exact accepted release commit.
