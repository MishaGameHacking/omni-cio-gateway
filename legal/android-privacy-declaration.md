# OMNICIO Android — фактические данные и разрешения

Редакция для Android 2.8.0, versionCode 11. Сверяется с exact signed release перед публикацией.

## Серверная обработка

Приложение требует аккаунта OMNICIO. Вход использует Telegram или VK ID через серверный API. Пользователь принимает актуальные условия, политику и согласие. Авторизация и изоляция аккаунтов проверяются сервером.

Read-only токен Т-Инвестиций после отдельного согласия передаётся серверу OMNICIO по HTTPS и сохраняется там зашифрованным существующим broker service. Приложение не отправляет торговые поручения или переводы. Подключение можно удалить в настройках. Credential не возвращается клиенту и не передаётся AI.

Портфель, снимки, история, цели и события хранятся на сервере. Приложение загружает их для текущего отображения. Это не local-first продукт, и персональные данные не объявляются отсутствующими.

## На устройстве

В SharedPreferences сохраняются тема, скрытие сумм, запрет скриншотов и защита входа. Старые demo/fixture preferences очищаются. Финансовые ответы и вводимый broker token существуют только в памяти процесса. Только сессия OMNICIO сохраняется зашифрованной AES-256-GCM с ключом Android Keystore в каталоге вне резервного копирования. При запуске сервер проверяет сессию; после отзыва/истечения требуется новый вход. HTTP cache выключен, редиректы запрещены. Автоматический Android backup выключен.

## Разрешения и защита экрана

`INTERNET` необходим для HTTPS API. Runtime-разрешения уведомлений нет; push-доставка не заявляется. Скриншоты разрешены по умолчанию; переключатель «Запретить скриншоты» включает FLAG_SECURE. `USE_BIOMETRIC` нужен для отдельной необязательной защиты входа: системная проверка отпечатком/кодом устройства. Приложение не получает и не хранит биометрические данные. Обычная работа TalkBack проверяется на устройстве.

## Выход и отключение

Выход сразу удаляет сохранённую сессию и состояние клиента, затем запрашивает отзыв на сервере. Недоступность сервера не препятствует локальному выходу и не считается подтверждением серверного отзыва. Переключение счёта сохраняет историю на сервере; прежний портфель не отображается как новый.

## Ограничения выпуска

Нет деморежима, платежного SDK, RuStore Push, рекламного SDK или автоматической торговли. Открытие legal/source ссылок происходит во внешнем браузере по действию пользователя. Для модерации нужен отдельный тестовый аккаунт и согласованный сценарий без передачи production secrets в карточке приложения.

Вход по выбору пользователя: Telegram OIDC (проверенный subject) или VK ID (проверенный user ID). Социальные токены не сохраняются, личные сообщения, контакты и телефон не запрашиваются. Привязки и сессии хранятся на сервере; клиентская сессия — в зашифрованном хранилище устройства.
