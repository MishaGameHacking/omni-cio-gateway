# OMNICIO Android — фактические данные и разрешения

Редакция для Android 2.6.1, versionCode 9. Сверяется с exact signed release перед публикацией.

## Серверная обработка

Приложение требует аккаунта OMNICIO. Регистрация/вход/восстановление используют email API сервера. Пользователь принимает актуальные условия, политику и согласие. Авторизация и изоляция аккаунтов проверяются сервером.

Read-only токен Т-Инвестиций после отдельного согласия передаётся серверу OMNICIO по HTTPS и сохраняется там зашифрованным существующим broker service. Приложение не отправляет торговые поручения или переводы. Подключение можно удалить в настройках. Credential не возвращается клиенту и не передаётся AI.

Портфель, снимки, история, цели и события хранятся на сервере. Приложение загружает их для текущего отображения. Это не local-first продукт, и персональные данные не объявляются отсутствующими.

## На устройстве

В SharedPreferences сохраняются только тема и скрытие сумм. Старые demo/fixture preferences очищаются. Финансовые ответы, пароли, вводимый broker token и session cookies существуют только в памяти процесса. HTTP cache выключен, редиректы запрещены. После завершения процесса требуется новый вход. Автоматический Android backup выключен.

## Разрешения и защита экрана

`INTERNET` необходим для HTTPS API. Runtime-разрешения уведомлений нет; push-доставка не заявляется. FLAG_SECURE защищает экран с персональными данными от штатных скриншотов/записи. Обычная работа TalkBack проверяется на устройстве.

## Выход и отключение

Выход отзывает текущую серверную сессию и очищает состояние клиента после подтверждения. При ошибке отзыва интерфейс показывает ошибку; отзыв не считается успешным. Завершение процесса очищает memory-only cookie, но само по себе не подтверждает серверный отзыв. Отключение счёта удаляет существующее серверное подключение; это не удаление всей истории аккаунта.

## Ограничения выпуска

Нет деморежима, платежного SDK, RuStore Push, рекламного SDK или автоматической торговли. Открытие legal/source ссылок происходит во внешнем браузере по действию пользователя. Для модерации нужен отдельный тестовый аккаунт и согласованный сценарий без передачи production secrets в карточке приложения.
