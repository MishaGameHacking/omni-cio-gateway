# OMNICIO 2.5.0 — черновик карточки RuStore

Статус: UI-06 release-candidate draft. Финальные тексты и изображения утверждаются только после exact-head QA, подписанной release-сборки и проверки фактического поведения.

## Название

OMNICIO

## Краткое описание

Локальный инвестиционный помощник: портфель, важные события и сценарии.

## Подробное описание

OMNICIO — нативное Android-приложение с local-first подходом к инвестиционному интерфейсу.

В текущем release-candidate пользователь может открыть приложение без обязательного аккаунта OMNICIO, посмотреть demo/fixture портфель и обзор, проверить состояния offline/stale/partial/error, открыть карточки позиций, увидеть автоматическую ленту существенных событий без свободного AI-чата и настроить локальные параметры интерфейса.

Раздел настроек показывает, какие данные считаются локальными, состояние demo T-Invest read-only подключения, резерв и горизонт цели, уведомления, фоновые ограничения Android, экспорт и удаление локального fixture-состояния.

Текущая версия честно маркирует demo/fixture данные. Реальный T-Invest token, production broker transport, покупки подписки и отправка сделок в UI-этапе не подключены.

OMNICIO не является WebView-обёрткой старого сайта. Основной интерфейс реализован нативно на Kotlin и Jetpack Compose.

## Что нового в 2.5.0

- Завершён UX трёх основных вкладок и настроек.
- Добавлены compact/standard/wide состояния интерфейса и улучшена работа с увеличенным шрифтом.
- Добавлены offline/stale/partial/error и revoked-token demo-состояния.
- Добавлен Android 13+ flow разрешения уведомлений.
- Показаны ограничения Battery Saver и Data Saver без обещания фоновой работы 24/7.
- Добавлены внутренние deep links OMNICIO.
- Добавлено crash-safe состояние локальной миграции UI-state.
- Подготовлена release-signing guard: release packaging не должен выполняться без защищённых signing credentials.

## Путь для модерации без production secrets

1. Установить release-candidate.
2. Выбрать «Попробовать локально».
3. Проверить «Обзор», «Портфель» и «Помощник».
4. Открыть «Настройки» и проверить privacy/local-data, demo T-Invest state, notifications и runtime ограничения.
5. Для QA-состояний использовать только явно помеченные demo/fixture переключатели.

Production broker token для проверки UI не требуется.

## Разрешения и данные

- Android 13+: `POST_NOTIFICATIONS` — только для показа уведомлений после пользовательского разрешения.
- Основной local-first UI работает без обязательной регистрации OMNICIO.
- Текущий UI release-candidate не запрашивает реальный T-Invest token.
- Локальный экспорт запускается только пользователем через Android share chooser.

Полная текущая декларация: `legal/android-privacy-declaration.md`.
