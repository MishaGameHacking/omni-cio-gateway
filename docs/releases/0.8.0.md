# Analyst AI 0.8.0-preview — Workspace

F01.2: полный визуальный каркас Android 16+ по указанию владельца от 17.10.2026.

- Новая композиция главной и навигация: Капитал, Портфель, Действия, Риски, Профиль.
- Общий дизайн всех экранов: поверхности, цветовые акценты, объём и нативное движение.
- Портфель с фильтрами и группировкой; инструмент разделён на позицию, условия и паспорт.
- Компактные риски и уведомления с отдельными подробностями события.
- Экраны оформления, ассистента, рынка и конструктора стратегии.
- Сохраняемые настройки внешнего вида; действующий инвестиционный профиль сохранён отдельно.
- Убрана техническая витрина с главной. Вход, реальные данные, операции, выплаты и проверка обновлений сохранены.

Расширенная стратегия пока является черновиком. Свободный чат, полный каталог рынка и
расчёт конкретных торговых действий ещё не подключены. Интерфейс не выдаёт их за готовые
расчёты, не создаёт заявки и не подставляет демонстрационные деньги.

Сборка, lint, чистая установка, обновление с 0.7.6 и UI на Android 16 (включая 200% шрифт) прошли.
