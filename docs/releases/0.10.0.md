# Analyst AI 0.10.0-preview / 34

F01.4 / F22 — столбчатая история стоимости и Android 15+.

- «Портфель → Динамика»: линии заменены округлыми столбцами в палитре Spectrum.
- Касание или горизонтальное проведение выбирает интервал. Подсказка показывает дату и баланс; ниже — изменение стоимости, минимум/максимум и реальные денежные потоки этого интервала.
- День, месяц, 6/12 месяцев, начало года, всё время и произвольный период. Расходы, оборот и точные наблюдения раскрываются по запросу.
- Один снимок уже виден. Пустые интервалы не превращаются в нули; отрицательные суммы показываются относительно нуля. Скрытие сумм действует на график, подсказки и статистику.
- Минимальная ОС — Android 15 / API 35; целевая — Android 16 / API 36. Сохранены package, подпись и существующие серверные данные.

Это история сохранённых оценок портфеля, не график свечей инструмента и не обещание прибыли. Пополнения/выводы отделены от результата инвестирования. Расчёт полной доходности и новые инвестиционные алгоритмы остаются отдельным этапом.

Матрица выпуска: чистая установка, запуск и полный UI на API 35 и 36; обновление 0.9.0 → 0.10.0 на API 36. Предыдущий 0.9.0 требовал API 36, поэтому обновление с него на API 35 не заявляется. Проверка эмулятора не подтверждает физический телефон.

Официальные основания: [Android 15 и системные отступы](https://developer.android.com/about/versions/15/behavior-changes-15), [доступность Compose](https://developer.android.com/develop/ui/compose/accessibility/semantics).
