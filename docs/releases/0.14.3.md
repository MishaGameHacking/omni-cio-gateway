# Analyst AI 0.14.3-preview — переход к серверной версии

Оболочка50 показывает версию работающей системы с Timeweb отдельно от номера
Android-клиента. Серверные данные, скрипты и алгоритмы остаются на Timeweb;
совместимые изменения backend не требуют нового APK.

Оформление и защита снимков экрана автоматически сохраняются на сервере.
Изменённые поля объединяются с последним серверным состоянием с проверкой
версии; подтверждение старого запроса не стирает более свежий выбор.
При отсутствии связи интерфейс явно показывает неподтверждённое состояние.
Очередь и локальная копия настроек изолированы по пользователю.

Это переходное обновление нативной оболочки. Исходник подготовлен; фактические
результаты сборки, серверного развёртывания и публикации фиксируются отдельно.
Реальная торговля не включается. Физическая установка на телефон не подтверждена.
