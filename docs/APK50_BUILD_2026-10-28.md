На главной после портфеля, состояния и ограничений добавлена карточка «Данные
для анализа». Она показывает номер установленной версии и открывает существующий
частичный анимированный диалог. Диалог читает /workspace/system-readiness для
выбранной валюты: независимые времена проверки/оценки, свежесть всех переданных
разделов, неполноту, источники и ограничения. Запрос выполняется только при
открытой панели; повторное чтение раз в60сек только на переднем плане. Это чтение
сохранённых сведений, не новая оценка портфеля и не разрешение на торговлю.

Модель отклоняет неверную схему, строковые булевы значения, недостоверные часы,
дубликаты и неполные строки. Отсутствующие/повреждённые сведения не становятся
зелёным состоянием. Прогресс показывает долю актуальных разделов данных, а не
готовность всего плана. Список разделов не обрезается искусственным лимитом.
При сбое обновления сохранённые сведения помечаются как последние полученные.
