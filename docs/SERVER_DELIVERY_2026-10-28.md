# Analyst AI: исходники, проверка и серверный выпуск

Действующее указание владельца от 28.10.2026:

- GitHub хранит исходники и управляет заданиями через API.
- Разработка, компиляция и тесты выполняются на LAPTOP-NPSGA016 и его WSL.
- Timeweb 9417611 исполняет рабочий backend, хранит данные и готовые пакеты.
- Установленный Android-клиент обращается к этому backend. Серверные исправления,
  данные, настройки и аналитика обновляются без выпуска или переустановки APK.
- Версии backend и Android выпускаются независимо. Не изменять APK, его манифест,
  сертификат и номер версии ради серверного исправления.

`server-runtime.yml` проверяет точный коммит на ноутбуке: аудит Python,
проверки CI, полный backend в WSL, зависимости и health/OpenAPI. Затем создаётся
пакет изменённых серверных модулей с SHA-256, исходным коммитом и хешами прежней
установки. Пакет не является результатом развёртывания до отдельной проверки
живого Timeweb. Не считать загруженный GitHub-код уже исполняющимся на сервере.

Текущий клиент использует `/workspace/live`: изменения БД и серверного кода
меняют revision; приложение повторно читает данные при получении изменения
и восстанавливает связь после перезапуска backend. Открытие интерфейса не
запускает платный анализ. Сохранить авторизацию, привязку владельца и данные.

Нативные Compose-экраны уже установленного APK исполняются на телефоне.
Серверное обновление не переписывает их Kotlin-код. Новые серверные возможности
должны сохранять контракт существующего клиента; перенос самого интерфейса
на сервер потребует поддержки такого интерфейса клиентской оболочкой.

В этом выпуске проверяются транзакционные исправления инициализации backend
из `45168fa6ec2a5d98ba72ea013ed2a7b34a4d7201`. Рабочая база, секреты,
нативные экраны и торговые права не входят в пакет. Проверки нового запуска
публикуются отдельно; прежние неуспешные результаты не переименовываются в PASS.

## Независимая версия системы

`/workspace/version` и поле `server_version` в `/automation/status` сообщают
версию `srv-<12 символов SHA256>` и полный `source_revision` с schema_version=1.
Она вычисляется один раз при загрузке процесса из отсортированных Python-модулей
backend и requirements.txt. Время, данные пользователя, окружение и секреты
не входят в этот идентификатор. Повторный запуск тех же исходников сохраняет
версию; откат возвращает прежний идентификатор. Это версия кода, а не свежесть
котировок или завершённость инвестиционного плана.

Новый клиент читает поле в уже существующем запросе статуса настроек, при
foreground/live-инвалидации, каждые20 секунд видимого экрана и при открытии
«О приложении». Поле отсутствует или повреждено — версия неизвестна; сетевой
сбой — последняя полученная версия явно помечена. BuildConfig показывается
отдельно как номер оболочки. Для APK49 этот код пока только в исходниках:
сервер не может переписать скомпилированный Compose-экран установленного APK.
