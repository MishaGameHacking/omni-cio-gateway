# Timeweb: основное рабочее место Analyst AI

Все редактирование, проверки и сборки выполняются на единственном постоянном
сервере проекта. GitHub — резервная копия и ранее разрешенный SSH/API транспорт.
Не создавать отдельные серверы для сборки или временных проверок.

Основные исходники: /srv/analyst-ai/workspace. Все ветки и теги GitHub загружены.
Существующие изменения Android сохранены. Не выполнять reset/clean поверх них.
Приложение остается строго портретным; package и прежняя подпись сохраняются.

Production: /opt/analyst-ai; конфигурация /etc/analyst-ai; данные и публичный
APK-канал /var/lib/analyst-ai. Разработка не читает production backend.env.
Build-пользователь analyst-build не имеет доступа к пользовательской БД и
production секретам. Его среда и отчеты: /var/lib/analyst-ai-build,
Gradle cache: /var/cache/analyst-ai/gradle, SDK: /opt/analyst-android-sdk.

Команды администратора:

- analyst-workspace check — проверки Python/Node/backend на самом Timeweb.
- analyst-workspace build — все Android варианты, JVM, lint, подпись и APK.
- analyst-workspace runtime — полные API37 матрицы 4KB/16KB, затем общий отчет.
- analyst-workspace publish — публикация только проверенных текущих байтов
  через существующий backend.release_publication, с ростом versionCode.
- analyst-workspace status — фактическое состояние, память, место, отчеты.

Этапы запускаются последовательно в systemd под analyst-build, с ограничениями
CPU, RAM и доступа к файлам. APK не публикуется после одного assemble.
Запуск этапа не означает прохождение: смотреть *-result.json и systemd status.
Публикация требует текущих успешных check/build/runtime и совпадающих SHA256.
Нативный код изменяется на телефоне только после установки нового APK.
