# Master plans Omni-CIO

Эта папка хранит исходную пользовательскую спецификацию и текущий порядок разработки.

## Текущая обязательная продуктовая спецификация

- [`OMNI_CIO_PORTFOLIO_GPT_RESET_V1.md`](OMNI_CIO_PORTFOLIO_GPT_RESET_V1.md) — узкий scope: существующий Custom GPT внутри ChatGPT, работа только с личным инвестиционным портфелем, новостями, кредитными рейтингами, подбором активов и диверсификацией.
- Отдельный сайт, web-кабинет, мобильное приложение, собственная AI-модель, Telegram и автономное исполнение исключены.
- `trading_methods=false`, GET-only Actions и `app:app` сохраняются.

Этот файл имеет приоритет для текущего продукта и следующего порядка работ.

## Правило конфликтов

При конфликте с portfolio-only scope:

- сайт, web-кабинет и мобильное приложение считаются исключёнными;
- Telegram считается полностью исключённым;
- собственная AI-модель считается исключённой;
- автономное исполнение считается запрещённым;
- Shadow/Paper/Preview/Confirm-before-trade не являются текущим roadmap;
- backend-функция сохраняется только при доказанном использовании в end-to-end работе Custom GPT.

## Правило изменений

- не считать цель реализованной без кода, тестов и acceptance;
- каждый пакет вести отдельной веткой и PR;
- не хранить токены, ключи, полные номера счетов и реальные брокерские данные;
- обновлять status и issue #27 после свежей проверки GitHub;
- исходные PDF не редактировать;
- новую продуктовую версию фиксировать отдельным документом и migration note.
