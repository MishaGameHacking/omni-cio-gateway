# Master plan Omni-CIO

Эта папка хранит исходную пользовательскую спецификацию развития Omni-CIO.

## Канонические файлы

- `OMNI_CIO_MASTER_PROMPT_V9.pdf` — исходный приложенный документ, 39 страниц.
- `OMNI_CIO_MASTER_PROMPT_V9.txt` — машинное извлечение текста для поиска, code review и AI-контекста; при расхождении приоритет у PDF.

Исходное имя вложения: `Мастер-промт Omni-CIO(9).pdf`.

SHA-256 PDF: `1fa50e7ca08f9701879bbc98c77f04e12cd66d52d2802e5f44d360e620f530f8`.

Аудит 2026-07-30 подтвердил, что приложенные версии `(8)` и `(9)` побайтно идентичны, поэтому в репозитории хранится одна каноническая копия v9 без дубля.

## Иерархия источников

1. Код, тесты и фактический `main` определяют реализованное поведение.
2. `AGENTS.md`, Regression Shield и security policies определяют обязательные технические границы.
3. Этот master plan определяет согласованный объём и направление программы.
4. `knowledge/16_CURRENT_PROGRAM_STATUS.md` определяет, что уже завершено и какой пакет следующий.
5. Профильные `knowledge/`, `docs/` и `gpt/` уточняют отдельные контуры.

Будущие цели master plan не являются разрешением считать их реализованными. В частности, описание подтверждаемого торгового исполнения не отменяет текущие инварианты `trading_methods=false`, GET-only Actions и отсутствие broker write methods. Любое изменение этого режима требует отдельного решения владельца, threat model, реализации, тестов, production acceptance и отдельного PR.

## Правило изменений

- не редактировать PDF;
- не подменять требования предположениями;
- изменения статуса фиксировать в `knowledge/16_CURRENT_PROGRAM_STATUS.md`, а не переписывать исходный план;
- каждый функциональный пакет вести отдельной веткой и PR;
- не хранить рядом токены, ключи, реальные номера счетов или брокерские отчёты.
