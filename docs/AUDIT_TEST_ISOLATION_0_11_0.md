# Регрессия полного CI: изоляция decimal-контекста

F01/F16/F22/F23, PR #880. Продолжение исправлений `2c2f0f7` и `c663da6`.
Никаких merge, Timeweb/deploy, изменений серверного APK, платёжных лимитов или
реальных финансовых операций. Исправление касается только теста и этого отчёта.

В полном Backend CI новый тест сохранения decimal-контекста получил уже
установленный флаг InvalidOperation от предшествующих вычислений. Это не
неправильная сумма: проверка точного результата прошла, неверным было
предположение теста, что localcontext начинается с пустыми флагами.
Python копирует текущий контекст вместе с сохраняющимися до очистки флагами.
Локально воспроизведено: исходный тест проходит при чистом контексте и падает,
если до входа установлен InvalidOperation.

Тест теперь явно проверяет оба состояния (чистое/установленный флаг) при
точностях 2, 6, 28 и 60. Проверяются неизменность всех флагов и traps,
precision, rounding, Emax и точный результат. Никакие ошибки не игнорируются,
проверка не удалена; вместо 4 комбинаций выполняются 8. Чистый контекст
проверяется на отсутствие новых флагов, существующий — на полное сохранение.

Локально после исправления: 28 тестов денежного модуля; весь доступный выбранный
backend-набор — **161 passed**. Параллельный отдельный процесс: **14 passed,
7 subtests passed** для session rotation/font cleanup. compileall успешен.
Это не весь репозиторий и не подтверждение эмулятора или телефона.
Для нового коммита требуется повторный полный Backend/Android/Sonar CI.

Официальная семантика:
https://docs.python.org/3/library/decimal.html

Последний полный успешный Android 15/16 прогон не подтверждён. Не допускается
выдавать APK как проверенный только на основании этих локальных результатов.
