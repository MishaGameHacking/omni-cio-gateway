# Analyst AI 0.11.0 — единственный владелец

## Указание OWNER 19.10.2026, 09:28 UTC

Продукт работает только на владельца: только его подтверждённая личность,
портфели, брокерские счета, задания, уведомления и бюджет. Несколько устройств
и счетов одного человека сохраняются. Многопользовательский режим и запас
ресурсов для других людей больше не являются целевым требованием. Это заменяет
прежнюю установку «до пяти аккаунтов» в AGENTS и MASTER_PLAN.

3D/Filament, все инвестиционные возможности и сильные модели сохраняются.
Идентификатор владельца в таблицах — связь данных, а не разрешение другим людям.
Подтверждённые данные, авторизация, шифрование, резервное восстановление,
контроль расходов и координация параллельных задач сохраняются.

## Границы перехода

Нельзя назначать владельца по username, имени в Timeweb, GitHub-профилю или
правилу «первый вошедший». Нужна явная привязка проверенной Telegram-личности.
Старые чужие записи не присваиваются владельцу и не удаляются автоматически.
Все входы, восстановление сеансов и фоновые задания требуют owner-проверки.

Ресурсы выбираются по измеренным пикам работы одного владельца, а не по
гипотетическому массовому использованию. Рабочее пространство ОС, обновления,
SQLite WAL, журналы и восстановление тоже потребляют диск: 2,7 ГБ данных
приложения не являются доказательством достаточности диска 3 ГБ.

По документации Timeweb основной диск нельзя уменьшить на месте. Для меньшего
диска нужен перенос на новый сервер и проверка восстановления/переключения.
Старый действующий сервер удаляется только после проверки замены и зависимостей,
не одновременно с началом переноса. Название stage не доказывает ненужность.

Прежний запрет выдавать непроверенный 0.11.0 за релиз и менять серверный APK/
канал до завершения сохраняется. В этом проходе автоматический deploy и merge
не разрешаются. Сначала инвентаризация, код и тесты; затем проверенный переход.

## Фактическое состояние

Начальный срез: 33478e38174afca685d6f736b2139ad42215ba65, PR #880.
Добавлена GET-only инвентаризация Timeweb через существующий GitHub secret
TIMEWEB_CLOUD_TOKEN. Она выводит только разрешённые метаданные серверов/агентов,
отказывается следовать redirect, не выводит тела ошибок/ключи и не меняет ресурсы.
Это не измерение живой нагрузки и не завершённая owner-only реализация.
