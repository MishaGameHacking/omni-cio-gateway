# Аудит 0.11.0 — 19.10.2026

Пункты плана: **F01 / F16 / F22 / F23**. Ветка `codex/spectrum-3d-100`, PR #880.
Опубликованная версия и Timeweb не меняются. Никаких merge, production deploy,
торговых поручений или изменения платёжных лимитов этот аудит не разрешает.

## Первый исправляемый дефект: поворот закрытого сеанса

База проверки: `93420da3d58581e33ba1eb5d10211286bfa4cb76`.
Android CI #637 (`39203888227`) остановился в `session_context_probe._rotate_signed_out`.
Этот сценарий использовал только `settings user_rotation`, хотя spatial-сценарий
уже использует общий `emulator_rotation.physical_quarter_turn`. Поэтому логическая
landscape-конфигурация не гарантировала такой же ориентации PNG консоли.

Теперь сценарий закрытого сеанса использует тот же физический поворот AVD.
Проверяются закрытое состояние и геометрия до и после получения неизменённого PNG;
размеры PNG должны точно совпасть с дисплеем. Старый портретный кадр допускает
только ограниченное ожидание нового кадра, а не поворот/масштабирование пикселей.
Обратный поворот и исходные настройки сохраняются даже при неуспехе сценария.

Отдельный дефект: `exercise_session_context` раньше возвращал font_scale к 1.0
только после успешного прохождения и записи отчёта. Теперь исходное значение
(включая отсутствие настройки) восстанавливается в контексте при ошибке,
раннем выходе и успехе. Ошибка очистки не скрывает исходную ошибку и не позволяет
записать положительный receipt, если сами сценарии успешны, а восстановление нет.

## Проверка и границы

Исходные три файла получены с точного SHA; локальные байты сверены с Git blob SHA.
Новый набор unit-тестов воспроизводит расхождение физического и логического
поворота и отсутствие восстановления font_scale на прежнем исходнике.
После исправления **14 тестовых методов прошли**; Python compileall успешен.
Это управляемые unit-симуляции. Они не подтверждают эмулятор или телефон.
Полный существующий Android/Backend/Sonar pipeline требуется для нового SHA.

Синтетические проверки A/B, изоляция контекста и проверка явного выхода не удалены.
Проверки APK и 16-КБ среды, допуски геометрии и качества не ослабляются.
Hosted Linux stock-control из предыдущего запуска не стартовал из-за ограничения
учётной записи GitHub. Это отдельная блокировка инфраструктуры, не результат
проверки исходников; платёжные настройки и этот диагностический gate не изменены.

Продолжается отдельный разбор финансовых расчётов, очередей ИИ и остальных
сценариев ввода. Результаты прежних коммитов не являются полной приёмкой 0.11.0.
Настоящий документ не объявляет ручной аудит всех файлов завершённым.
