# F01.3 — UX100, актуальность интерфейса 0.10.0

Исходная карта 100 решений относится к выпущенному 0.9.0 / 33. Сверка
**17.10.2026** учитывает последующее уточнение F01.4: в 0.10.0 / 34 история
стоимости стала столбчатой, расширен выбор периода и добавлена статистика
выбранного интервала. Текущая платформа — Android 15+ (`35 / 36 / 36`).
Публикация и доставка записаны в [PLAN_STATUS](PLAN_STATUS.md), визуальный
контракт — в [WORKSPACE_UI](WORKSPACE_UI.md). Эта карта не закрывает
отсутствующие инвестиционные алгоритмы.

OWNER 17.10.2026 разрешил реализовать 100 пунктов аудита в новой версии интерфейса. Новая инвестиционная логика будет подключена позднее. Карта ниже отделяет работающие локальные взаимодействия от компонентов, ожидающих проверенные серверные данные. «UI» означает реализованную поверхность/взаимодействие; «Данные» — готовое состояние или контракт отображения, для которого отсутствует новый расчёт. Это не обещание доходности или готовности всех алгоритмов.

Исходники находятся в `app/src/main/java/ru/omnicio/app/ui/`. Синтетические заполненные состояния — только в `app/src/debug`, с постоянной надписью «ВИЗУАЛЬНЫЙ ТЕСТ · НЕ РЕАЛЬНЫЕ ДАННЫЕ». В production нет демонстрационных денег и сделок.

## Историческая проверка 0.9.0 / F01.3

Для выпуска 0.9.0 локальные Python regression gates включали 365 проверок с одним предусмотренным skip. Debug probe выполнял 24 дополнительные поведенческие проверки UX (поиск, валютная сопоставимость сортировки, актуальность событий, dirty-сводка, статусы, время). На эмуляторе проверялись темы, большой шрифт, возврат, поиск/сброс, сохранение стратегии, график, скрытие сумм, откладывание действия и раскрытие события. CI собирал debug/release/preview и проверял APK, подпись и обновление с опубликованного 0.8.0. Приведённые ниже запуски относятся к этому историческому выпуску; физический телефон отдельно не проверялся.

Проверки завершены: [интерфейс #873](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/39026729076), [уточнённый снимок графика и доставка #874](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/39028869631), [публикация APK](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/39027844102), [совпадение APK и публичного канала Timeweb](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/39029899747). Исправленный график, сравнение, узкая навигация, стратегия и крупный шрифт просмотрены. Наличие готового интерфейса не означает выполнение будущих серверных расчётов.

## Проверка текущего 0.10.0 / F01.4

[Публикация 0.10.0](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/39042091615)
подтверждает чистую установку и запуск опубликованного preview на Android 15 / API 35
и Android 16 / API 36, а также обновление с 0.9.0 / 33 и запуск после него на API 36.
Взаимодействия интерфейса проверены отдельным debug fixture на обоих API;
синтетические данные не входят в распространяемый preview. Установка через ADB
на эмуляторе не подтверждает установку на физическом телефоне или через UI updater.
Точные байты APK и границы проверки описаны в [release notes 0.10.0](releases/0.10.0.md),
результат доставки — в [PLAN_STATUS](PLAN_STATUS.md).

## Следующий этап данных

Требуются серверные источники: подтверждённые группы эмитентов, параметры выпусков, квалификация, выполнение стратегии, чистый инвестиционный доход, события пополнений/выводов, план действий и его исполнение, комплексные категории риска, идентичность повторных событий, доставка по расписанию и чат. Существующие API не заменяются выдуманными значениями; наличие готового компонента не закрывает эти пункты MASTER_PLAN.
