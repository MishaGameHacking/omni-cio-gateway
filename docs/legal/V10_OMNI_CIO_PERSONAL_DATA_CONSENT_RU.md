# Отдельное согласие на обработку персональных данных Omni-CIO

**Статус:** ПРЕДЗАПУСКОВОЙ ШАБЛОН / НЕ АКТИВИРУЕТ РЕГИСТРАЦИЮ  
**Дата редакции:** 21.09.2026

Этот документ используется только для тех операций Omni-CIO, для которых оператор
действительно выбирает согласие как правовое основание. Согласие оформляется отдельно
от пользовательского соглашения, политики обработки персональных данных и иных
подтверждаемых пользователем документов.

## 1. Граница согласия

Пользователь даёт согласие отдельным явным действием только на прямо перечисленные
в соответствующей форме данные, цель обработки, операции и срок.

Не считаются включёнными в такое согласие по умолчанию:

- реклама и маркетинговые рассылки;
- распространение персональных данных неопределённому кругу лиц;
- биометрические данные;
- специальные категории персональных данных;
- номер телефона или Telegram profile data;
- любые будущие цели, не указанные в отдельной форме.

## 2. Core-функции Omni-CIO

Регистрация, аутентификация, создание обычного пользовательского аккаунта, Tenant и
серверной сессии планируются не как скрытое пакетное согласие, а как обработка,
необходимая для заключения и исполнения пользовательского соглашения по инициативе
пользователя — пункт 5 части 1 статьи 6 Федерального закона № 152-ФЗ.

Это не позволяет использовать данные для несовместимых дополнительных целей.

## 3. Отзыв

Если обработка основана на согласии, пользователь вправе его отозвать через принятый
канал обращений субъектов персональных данных.

После отзыва оператор прекращает основанную на согласии обработку и уничтожает данные,
если отсутствует самостоятельное законное основание для их дальнейшей обработки,
в срок не более 30 дней в соответствии со статьёй 21 Федерального закона № 152-ФЗ.

## 4. Предзапусковая граница

Шаблон не разрешает публичную регистрацию. До активации должны быть приняты
российская primary database authority, регуляторные уведомления, трансграничная
оценка, финальный канал обращений субъектов и опубликованная политика обработки
персональных данных.
