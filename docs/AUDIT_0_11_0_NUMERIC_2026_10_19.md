## Reproduced defects and fixes

1. assess_scenarios used localcontext() with only prec=34. This copied caller
   rounding, exponent bounds, signal traps and formatting. Valid finite inputs
   could fail with Inexact/Rounded, or produce different results depending on a
   worker's context. A fresh, fully specified Decimal Context now owns arithmetic
   and restores the caller context on success or error. Precision remains 34;
   fees, inflation, joint probabilities, quantile/tail rules and input limits
   are unchanged. No market forecasting accuracy is implied.
2. approved_candidates tested `if not raw` before its string type check. A
   malformed injected configuration mapping containing None, False, numeric zero
   or empty containers silently selected the legacy route. Validation now runs
   before the empty-string fallback. A missing key or explicit empty string
   still selects the existing legacy configuration. Normal os.environ values
   are strings; this is defensive validation for supplied configuration maps,
   not a claim of a demonstrated production attack or paid-model incident.
