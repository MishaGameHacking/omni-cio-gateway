# Analyst AI — надёжность автономного анализа

## Статус поставки

Это серверные исходники после 0.5.1, не объявление установленного обновления.
Android остаётся 0.5.1 / 22 с московским адресом. Обычное развёртывание Timeweb
остаётся приостановленным; код нельзя считать работающим в production без
отдельного проверенного развёртывания. Новые серверы, модели или подписки этим
изменением не покупаются. Тестовые ключи/цены используются только в MockTransport.

## Что подключено к существующему приложению

- Планировщик сохраняет задания в SQLite и выбирает их атомарно. На пользователя
  не более одного queued/running задания; повторные запросы объединяются.
- POST /analysis/refresh возвращает HTTP 202 и состояние задания, не выполняя
  платный анализ внутри HTTP-запроса. Это служебная совместимость со старым
  клиентом; произвольный пользовательский промпт не принимается.
- Номер владельца и срок аренды задания проверяются перед сетевым запросом,
  под транзакцией резерва денег и перед записью снимка/результата/карточки.
- Временные ошибки чтения портфеля повторяются ограниченно. Истёкший running
  становится uncertain, а не автоматически переигрывается: прежний процесс мог
  уже отправить платный запрос. Последующие проверки правил продолжаются, но
  платные запросы пользователя с uncertain-заданиями приостановлены до сверки.
- /analysis/status сохраняет прежние поля Android и добавляет очередь, причины
  неготовности каждого маршрута и оценочную сумму пользователя за день.
- Без ключа, разрешения обработки, свежих цен и положительных рублёвых лимитов
  модель не вызывается. Алгоритмические предупреждения сохраняются.

## Денежный контроль

ai_budget.py использует целые микрорубли (1 ₽ = 1 000 000 единиц), Decimal для
конфигурации и BEGIN IMMEDIATE для общей проверки пользователя и проекта.
Сначала резервируется верхняя ОЦЕНКА, затем отправляется запрос. В оценку входят
UTF-8 размер подготовленных messages, задаваемый запас input tokens и output cap.
Это консервативная оценка, не универсальный tokenizer и не обещание точного счёта.

При валидной usage резерв заменяется рассчитанной стоимостью фактических токенов.
Даже неверный JSON модели учитывается. Таймаут, потерянный ответ или отсутствие
usage сохраняют полный резерв, включая следующие дни. Неожиданная модель или
превышение оценки блокируют дальнейшие платные обращения до ручной сверки.
Автоматическое переключение на дорогую модель и бесконечные повторы отсутствуют.
Ошибки маршрута включают паузу 5 минут. Последовательные запросы не расходуют
квоту только потому, что HTTP-запрос был отменён клиентом.

День нашего журнала — 00:00–24:00 по Москве. У Timeweb дневное окно отсчитывается
24 часа от первой траты, а не от полуночи. Лимиты на стороне Timeweb необходимо
установить отдельно; этот PR их НЕ настраивает. Все суммы API обозначены как
estimated/reserved, `provider_invoice_reconciled=false`. Интерфейс сверки счетов
и административное разрешение uncertain-исходов ещё не сделаны. Не удалять
строки резервов или uncertain-заданий для обхода лимитов.

## Два корректных режима подключения

`AI_TRANSPORT=gateway`: общий `TIMEWEB_AI_TOKEN`, базовый
`https://api.timeweb.ai/v1`, модель передаётся в `model`.

`AI_TRANSPORT=agents`: раздельные `TIMEWEB_AI_FAST_BASE_URL`,
`TIMEWEB_AI_STANDARD_BASE_URL`, `TIMEWEB_AI_PREMIUM_BASE_URL` и одноимённые
`*_TOKEN`. Адрес берётся с дашборда конкретного агента, формат
`https://agent.timeweb.cloud/api/v1/cloud-ai/agents/<access-id>/v1`.
Поле `model` не используется для выбора агента: модель задаётся его настройками.
Возвращённая модель должна точно совпадать с моделью, к которой привязана цена.
Несовпадение не исправляется молчаливым принятием неизвестного тарифа.

Оба режима используют `AI_MODEL_FAST`, `AI_MODEL_STANDARD`, `AI_MODEL_PREMIUM`.
Полный облачный токен `TIMEWEB_CLOUD_TOKEN` НЕ служит ключом вызова модели,
а `TIMEWEB_CLOUD_API_KEY` намеренно не используется как неявная замена.

Для каждого уровня `AI_<TIER>_` обязательны:

- `PRICING_MODEL`: точный идентификатор модели;
- `PRICING_VALID_UNTIL`: ISO 8601 с часовой зоной, проверенный тариф на период
  не более 7 дней вперёд;
- `INPUT_RUB_PER_MILLION`, `OUTPUT_RUB_PER_MILLION`: проверенные положительные цены;
- `TOKEN_PARAMETER`: `max_tokens` или `max_completion_tokens` по документации модели;
- `PROCESSING_REGION`: подтверждённый оператором двухбуквенный код страны;
- опционально `INPUT_TOKEN_ALLOWANCE` для накладного контекста (по умолчанию 4096).

Общие `AI_USER_DAILY_RUB` и `AI_PROJECT_DAILY_RUB` по умолчанию 0 (выключено),
не «безлимит». Автоматическая закупка лимита/мощности не выполняется.

## Обработка данных и условия включения

`AI_EXTERNAL_PROCESSING_APPROVED=true` и список `AI_ALLOWED_PROCESSING_REGIONS`
(по умолчанию RU) — обязательные явные настройки. Это утверждение оператора после
проверки поставщика, НЕ доказательство географии обработки по IP или наличию
московской VM. Иностранную модель нельзя объявлять российской из-за прокси Timeweb.

Модуль минимизации персонального контекста не внедрён в этом изменении.
Существующий контекст портфеля остаётся финансовыми данными пользователя.
До проверки его состава и согласованной политики передачи внешнюю интеграцию
НЕ ВКЛЮЧАТЬ. Никакие реальные ключи, счета или портфели не входят в тесты.
TLS обязателен; редиректы запрещены; адреса ограничены официальными конечными
точками Timeweb. Ответ ограничен по размеру и времени. Сообщения провайдера,
ключи и исходный финансовый контекст не помещаются в диагностику очереди.

## Гарантии и негарантии

Атомарный claim и fencing не означают exactly-once сетевой вызов. После обрыва
соединения нельзя доказать отсутствие списания; выбран безопасный uncertain.
Сохранение analysis_runs и insight_cards пока отдельные транзакции; полноценный
транзакционный outbox уведомлений остаётся задачей следующего этапа.
Проверка JSON/источника не является проверкой каждого экономического вывода.
Не добавлены мировые новости, ручной чат с моделью, сделки, push, авто-масштабирование,
регулярные бэкапы, реконструкция полной доходности или производственная подпись.

## Проверки и источники контрактов

`python -m unittest discover -s backend/tests -p 'test_*.py' -v`

Новые тесты покрывают конкуренцию квот, нулевые лимиты, полуночные переходы,
перезапуск очереди, истечение аренды, запрет повторной оплаты, неправильные модели,
истёкшие цены, region gate, отсутствие ключа, таймаут, 302, частичный ответ,
HTTP 202 и старый Android-контракт. Проверки выполняются без платных запросов.

Официальные контракты, проверены 13.10.2026:

- https://timeweb.cloud/docs/ai-agents/api-usage/openai-compatible-api
- https://timeweb.cloud/docs/ai-agents/pricing/token-limit
