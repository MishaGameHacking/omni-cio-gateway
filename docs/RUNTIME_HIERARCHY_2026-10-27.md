# Analyst AI: исполняемая иерархия и наблюдаемость

Разработка и проверки этого кандидата выполняются на существующем Timeweb 9417611.
Граф N00–N11 находится в backend/application_hierarchy.py, построение статуса —
в backend/workspace_readiness.py, проверка времён/ссылок — в backend/source_observability.py.

## Ответственность слоёв

Android отображает сохранённые серверные результаты и отправляет изменения настроек.
volume_workspace читает снимок текущего пользователя и брокерского подключения.
workspace_readiness объединяет уже прочитанные сведения без сети и записи.
source_observability раздельно оценивает время оценки портфеля, публикаций, операций,
выплат и календаря; существующие журналы остаются единственным источником данных.
application_hierarchy проверяет зависимости и не превращает наличие файла в приёмку этапа.
portfolio_accounting предоставляет арифметику сверки/TWR/XIRR только при полных входных данных.
paper_execution и run_paper_execution — изолированная симуляция без брокерского транспорта.

## API

GET /workspace/system-readiness требует прежнюю авторизацию. GET /workspace
получает дополнительную секцию system и три capability: public_sources, cash_ledger,
system_readiness. Чтение не запускает брокера, ИИ, миграцию или фоновую задачу.
Новое время evaluated_at не меняет valuation_as_of и времена свидетельств.
Новый нативный экран для этого API ещё не включён в APK.

## Проверка и границы

Проверяются границы свежести, будущие/неверные даты, конфликты source IDs,
неразрешённые ссылки, независимость времени событий от оценки портфеля,
отсутствие сети/записи при чтении, изоляция пользователей и смены брокерского токена.
Бесплатные внешние проекты не устанавливаются целиком; новая платная инфраструктура не нужна.
Ни одна из этих функций не включает реальную торговлю или платные AI-вызовы.
Полный N00–N11, четыре КРА, независимый реальный денежный учёт, sandbox,
30 торговых сессий и нативная приёмка не объявляются завершёнными.
