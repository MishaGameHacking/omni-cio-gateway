# Аналитика54 — реализация и границы

Кандидат, ещё не проверен и не опубликован. Рабочая база: APK53, backend4a154b1.

Исправление падения «План»: `/automation/strategy-plan` отсутствовал в allowlist
клиента; `require` выбрасывал необработанное исключение в `LaunchedEffect`.
Адрес разрешён; ошибки загрузки обрабатываются, отмена coroutine сохраняется.
Проверка клиента проходит транспорт и возвращает восстанавливаемую ошибку сети.

Горизонт показывается в годах; существующий серверный контракт хранит месяцы.
Ползунок отображает текущее положение, сохранение выполняется по завершении жеста.
Неполный профиль не изображается как готовый план «100% резерв».

«Аналитика»: обзор стоимости/выплат/структуры, отдельные подробности, выбор счёта,
валюты и периода. Серии получены из аутентифицированного API и сохранённых
наблюдений GetPortfolio. Между отсутствующими наблюдениями данные не выдумываются.
Для суммы счетов нужны совпадающие моменты наблюдения. Операции разных валют не
складываются. Пока нет полной проверенной базы денежных потоков и крайних оценок,
общий доход показывается как недоступный; изменение баланса не подменяет доход.
Это не доступ к внутреннему API исторической аналитики Т‑Банка.

Рублёвый остаток исключён из концентрации отдельной бумаги/эмитента/отрасли;
валютная концентрация продолжает проверяться отдельно. Повторные одинаковые
уведомления за24часа не создаются; аудит не удаляется. Изменение доли менее1п.п.
при прежнем превышенном лимите не создаёт отдельного уведомления, переход через
лимит и изменение лимита проверяются. В списке проверок — последние уникальные
состояния, а не повторяющийся журнал. Визуальные доли основаны на фактах сервера.

ИИ: подготовлен существующий GuardedAIClient для `dashscope/qwen3.5-flash`,
`enable_thinking=false`, JSON-ответ, без повторных оплачиваемых запросов и без
автоматического перехода к дорогой модели. Регион EXTERNAL означает явно
разрешённого внешнего провайдера, а не обещание обработки в РФ. Настройка ключа,
бюджета, актуальной цены и фактический успешный вызов должны подтверждаться
отдельной квитанцией. Наличие кода не означает подключённый ИИ.

## Проверенные первичные источники

- [Т‑Банк: аналитика портфеля](https://www.tbank.ru/invest/help/educate/yield-analysis/about/folio-lookup/).
- [T‑Invest API](https://developer.tbank.ru/invest/intro/intro): GetInfo даёт статус
  квалификации/тариф/права; даты рождения и возраста в публичной схеме нет.
- [Timeweb AI Gateway](https://timeweb.cloud/docs/ai-gateway/manage), каталог моделей
  проверен29.10.2026 через административный API: Qwen3.5Flash14₽/1млн входных,
  52₽/1млн выходных токенов; отдельный AI-ключ1₽/месяц. Цены не обещание будущих тарифов.
- [Официальный SDKTimeweb](https://github.com/timeweb-cloud/sdk-python): выделенный
  AI-ключ и entity-limits по деньгам, без передачи административного токена приложению.
- [Qwen OpenAI-compatible API](https://docs.qwencloud.com/api-reference/chat/openai-chat):
  параметр отключения thinking должен отправляться на верхнем уровне запроса.
- [Vico](https://github.com/patrykandpatrick/vico), Apache2.0, и
  [Lottie Android](https://github.com/airbnb/lottie-android), Apache2.0: изучены как
  возможные библиотеки. В этой реализации используются уже установленные AndroidX
  Compose Canvas/анимации и существующий SpectrumProgressBar; сторонний исходный
  код и анимационные файлы из этих репозиториев не копировались.

Пользовательские скриншоты, суммы и идентификаторы счетов не публикуются.
Реальные торговые поручения не отправляются. Гарантии доходности отсутствуют.
