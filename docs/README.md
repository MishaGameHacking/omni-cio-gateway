# Документация Analyst AI

Актуальная линия приложения — **0.10.0-preview / 34**, Android 15+.
[Обзор и APK](../README.md) · [Реестр реализации и доставки](PLAN_STATUS.md) ·
[Изменения 0.10.0](releases/0.10.0.md)

Разрабатываемое единое обновление — [3D100 / 0.11.0 / 35](3D100.md),
[PR #880](https://github.com/MishaGameHacking/omni-cio-gateway/pull/880).
[Описание кандидата](releases/0.11.0.md) не является объявлением публикации.

Этот индекс охватывает все документы проекта. Планы описывают утверждённую цель,
контракты — действующее поведение и его ограничения, исторические материалы —
состояние на дату исследования или инцидента. Наличие документа не подтверждает
готовность функции, серверную установку или проверку телефона.

## С чего начать

- Пользователю: [обзор приложения](../README.md), [установка APK](APK_INSTALLATION.md), [карта экранов](WORKSPACE_UI.md).
- Разработчику: [AGENTS.md](../AGENTS.md), [главный план](MASTER_PLAN.md), [F01–F23 и приёмка](PLAN_STATUS.md).
- Для выпуска: [release notes](releases/0.10.0.md), [проверка установки](APK_INSTALLATION.md), [единый updater](UPDATE_RUNTIME_UNIFICATION.md).
- Для оценки готовности: [PLAN_STATUS.md](PLAN_STATUS.md). Публикация APK, доставка на Timeweb и физический телефон учитываются отдельно.
