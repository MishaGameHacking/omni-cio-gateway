# OMNICIO — план интерфейса Android

Поручение владельца от 11.10.2026 заменяет прежний этап UI-01–UI-06 на fixtures. Исторические планы доступны в Git history. Основной режим использует Timeweb; деморежима нет.

## Пользовательский результат

1. Зарегистрироваться/войти в свой аккаунт и восстановить доступ через email.
2. Подключить собственный read-only счёт через защищённый серверный API.
3. Получить стоимость, остатки, позиции, источники и время с сервера.
4. Исследовать серверную историю стоимости через интерактивный график и значения.
5. Читать существенные серверные события и загружать историю ленты.
6. Смотреть и создавать собственные цели на сервере.
7. Управлять темой, скрытием сумм, подключением и выходом.

Приложение не выдаёт готовые цифры до ответа API. Недоступная функция не изображается работающей.

## Приёмка интерфейса

- Сохранить launcher icon и идентичность приложения.
- Удалить fixture providers, fake connection, QA/demo controls и старые demo preferences.
- Обеспечить светлую/тёмную темы, векторные значки, TalkBack-подписи и крупные зоны нажатия.
- Проверить телефон, широкий экран, увеличенный шрифт, IME и системные отступы.
- Проверить вход/регистрацию/код/восстановление; секретные поля не восстанавливаются с диска.
- Проверить пустой счёт, частичный снимок, отсутствующую цену, stale, offline, 401, 409 и ошибки API.
- Проверить поиск и длинный портфель без искусственного лимита, интерактивный график без вымышленных точек.
- Проверить отключение брокера и выход; другой пользователь не видит предыдущие ответы.
- Собрать lint/unit/debug APK через Gradle Wrapper и проверить exact APK на устройстве.

Материальная готовность определяется результатами этих проверок, а не наличием кода или зелёным единичным тестом. Неподписанный debug не является публикацией RuStore.
