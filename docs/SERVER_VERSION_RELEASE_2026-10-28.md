## Поведение

Идентификатор `srv-<12 символов SHA256>` соответствует Python-модулям и
requirements.txt, загруженным серверным процессом. Он меняется при изменении
кода или зависимостей и сохраняется при перезапуске тех же исходников.
Пользовательские данные, часы и секреты не входят в публичную версию.

Метаданные доступны авторизованному клиенту через `GET /workspace/version`
и существующий `GET /automation/status`; ответы запрещают кеширование.
Развёртывание также изменяет существующий live-маркер и вызывает обновление
данных у совместимых клиентов без изменения API live-ответа.

Подготовленный экран настроек показывает отдельно версию системы и версию
Android-оболочки. Используется существующее обновление статуса, включая
возобновление экрана, live-сигнал и открытие «О приложении».
При потере связи последняя полученная версия не выдаётся за подтверждённую текущую.
