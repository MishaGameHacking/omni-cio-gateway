## Как читать свидетельства

JSON в `evidence/` сохраняют результаты проверок и точные хеши. Полные журналы/JUnit находятся на Timeweb в каталоге `candidate-check-n02-n04-r4-20261027-20261027T061309Z-ea5fd07f/evidence`. Серверные пути, размеры и хеши первичных receipt указаны в манифесте применения.

Файлы исследований CBR с `internal_static_source_omitted_from_public_copy=true` — публикационные проекции первичных наблюдений. Из них исключены полные чужие JS-файлы и длинные фрагменты формы; сохранены адреса, времена, размеры, хеши и технические выводы. Хеш первичного серверного receipt не является хешем такой сокращённой проекции. Значения cookies/CSRF не публикуются. JSON реального поиска содержит только публичные факты, не пользовательский портфель.

Успешный health не означает полноту источников. Первый реальный цикл остался `events_partial/event_sources_incomplete` из-за состояния календаря; успешные операции сохранены независимо. Журнал ещё не является полным учётом доходности/налогов и независимой сверкой. N10 требует 30 настоящих торговых сессий, а Android-матрица, внешний gate и физическая установка остаются отдельными открытыми критериями.
