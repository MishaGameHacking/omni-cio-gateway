## Что исправлено

APK 49 показывал в «О приложении» вшитый BuildConfig, поэтому изменение backend
не меняло эту строку. Оболочка50 получает идентичность загруженных серверных
Python-модулей и requirements.txt из авторизованного API. На экране отдельно
показаны серверная система и оболочка Android. Версия проверяется при открытии,
возврате в приложение, событиях live и в активном профиле каждые 20 секунд.
Неподтверждённая/сохранённая версия не выдаётся за актуально проверенную.

Настройки оформления и блокирования снимков экрана сохраняются в БД отдельно
для пользователя. Изменения подтверждаются сервером, конфликты записи проверяются
по версии; отправляются только изменённые поля. Очередь изменений сохраняется
локально при отсутствии связи. Ответ на более старую запись не стирает новые
действия пользователя. Изменения на сервере входят в live-инвалидацию.
Имеющиеся API анализа, стратегии и уведомлений сохранены.

До подтверждения политики текущего аккаунта окно защищено FLAG_SECURE.
Сброс оформления сохраняет настройки приватности. Старые локальные настройки
мигрируют однократно; чужой аккаунт не наследует настройки уже определённого владельца.
