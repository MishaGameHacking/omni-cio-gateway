# OMNICIO — визуальный контракт Android

Редакция 11.10.2026. Брендовая launcher icon не изменяется.

## Основные решения

- Kotlin/Compose Material 3, единая типографика и интервалы из `ui/theme`.
- Нейтральная светлая и графитовая тёмная темы. Жёлтая основная кнопка сохраняет направление OMNICIO.
- Три вкладки: Обзор, Портфель, Помощник; Настройки открываются из верхней панели.
- На ширине от 600 dp нижняя навигация заменяется NavigationRail; содержимое ограничено читаемой шириной.
- Векторные Android drawable одного размера 24 dp, единая линия 1.8; никаких символов Unicode вместо значков.
- Touch target кнопок и переключателей — не меньше 48 dp; icon-only действия имеют contentDescription. Декоративные значки не дублируются в TalkBack.
- Длинные названия и увеличенный шрифт допускают переносы. Финансовые строки располагаются вертикально, не сталкиваются друг с другом.

## Информация и действия

На Обзоре сначала счёт и стоимость, затем состояние/время, деньги, история и действие обновления. Ни один график не является bitmap или заготовленной линией. История содержит выбор периода и точки, доступный список точных значений и отметку об ограниченном числе наблюдений. При скрытии сумм скрываются также график, количества и содержимое финансовых событий.

Список портфеля виртуализирован; поиск не ограничивает общее число позиций. Детали содержат валюту, количество, цену, долю, блокировку, время и источники. Лента помощника загружается постранично и не придумывает объяснений.

Loading, error, empty, stale и partial различимы текстом, а не только цветом. При недоступности API нет демонстрационных цифр. Вход, consent, выбор счёта и подтверждение отключения имеют действующие серверные consumers.
