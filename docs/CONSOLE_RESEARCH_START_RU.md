# Запуск анализа из консоли Timeweb

30 октября 2026 года в 21:31 МСК Timeweb подтвердил один запрошенный владельцем сброс пароля Linux `root` на облачной ВМ 9417611. Приложение после сброса ответило HTTP 200. SSH продолжает принимать только ключи. Повторная проверка временного ключа закончилась отказом до выполнения какой-либо команды на сервере. [Сброс](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/41107658480) · [Режим SSH](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/41108288292) · [Проверка ключа](https://github.com/MishaGameHacking/omni-cio-gateway/actions/runs/41098570663/attempts/3)

1. Откройте существующую ВМ **9417611** внутри своего личного кабинета Timeweb и перейдите в её консоль.
2. В поле `login` введите `root`. Новый пароль Linux, полученный через Timeweb, введите только в консоли. При наборе символы пароля обычно не отображаются.
3. После появления приглашения командной строки вставьте блок целиком.

```bash
analyst_kit=$(mktemp /root/analyst-research.XXXXXX) &&
curl -fsSL --proto '=https' --proto-redir '=https' 'https://raw.githubusercontent.com/MishaGameHacking/omni-cio-gateway/a13031c9a724d5bc42fd09e3aae447f030373df5/deploy/console-research-kit/analyst-research-853090e.pyz' -o "$analyst_kit" &&
printf '%s  %s\n' '05312df40d8d5621cd9cf66d43616feffbcb615b5220b0ff665d5e93a832e28a' "$analyst_kit" | sha256sum -c - &&
python3 -I "$analyst_kit"
```

Это неизменяемая версия пакета. Команда создаёт файл в каталоге администратора, скачивает 442 494 байта, сверяет SHA-256 и запускает установщик. Он проверит, что находится на нужной ВМ и что исходники, веса и предыдущая версия приложения совпадают с проверенной сборкой.

На первом запуске локальная модель должна обработать настоящий финансовый отчёт из базы сервера. После этой проверки установщик подключит обработку публичных отчётов к приложению. Для замены двух модулей службы приложения кратковременно перезапускаются. Ранее проверенный механизм делает приватную резервную копию и проверяет состояние приложения, конфигурации владельца и новой службы.

Успех подтверждает последняя строка `CONSOLE_RESEARCH_RESULT` со статусом `active` или `already_active`. Одна только строка `LOCAL_RESEARCH_ACTIVE` подтверждает лишь запуск модели, а не подключение к приложению. При ошибке достаточно передать строку с префиксом `CONSOLE_RESEARCH_ERROR`. Полный журнал, пароль, токен брокера и адрес консоли с параметром доступа для этого не нужны.

Пакет прошёл пять проверок поведения и три проверки настоящего исполняемого архива на ноутбуке владельца. Сборка содержит два модуля сервера и прежние проверенные операции установки. Её функция ограничена исследованием публичных отчётов. Исполнитель реальных заявок в неё не входит. На момент публикации запуск пакета в консоли этой ВМ ещё не подтверждён.
