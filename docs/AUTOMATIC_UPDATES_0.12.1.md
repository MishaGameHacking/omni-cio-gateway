## Подготовленное поведение

- При открытом приложении после успешной свежей проверки серверной версии обязательное обновление запускается автоматически, если Android уже разрешил установку из Analyst AI.
- APK проходит существующие проверки размера, SHA-256, package и сертификата. Используется прежняя линия ru.omnicio.app.debug и прежний ключ подписи.
- На один APK приходится одна автоматическая попытка в процессе. Повторный опрос и изменение описания релиза не создают новые попытки. После ошибки или отмены доступна явная повторная попытка.
- Сохранённая сессия PackageInstaller восстанавливается до автоматической операции; устранено окно между регистрацией и открытием новой сессии.
- Автоматический запуск работает в foreground. Фоновое обновление полностью закрытого приложения этой версией не реализовано.
- Установленная 0.11.0-preview / 35 содержит прежний ручной запуск. Первый переход требует кнопки «Обновить» в самом приложении после появления релиза на сервере. Изменение сервера не переписывает уже установленный код.
- Android может потребовать разрешение источника или подтверждение установки. Существующие REQUEST_INSTALL_PACKAGES, UPDATE_PACKAGES_WITHOUT_USER_ACTION и USER_ACTION_NOT_REQUIRED сохранены; системное согласие не обходится.

Платформенный контракт: https://developer.android.com/reference/android/content/pm/PackageInstaller.SessionParams#setRequireUserAction(int)

## Препятствие для публикации

На текущей VM отсутствуют /dev/kvm и CPU flags VMX/SVM. Отдельный stock Android API37 / 16384 без установки APK не завершил boot за 1800.382 секунды. Его собственный AVD удалён, процессы остановлены. Exit -9 относится к ограниченной очистке, а не доказанному самостоятельному падению Android.

Это не runtime-результат APK37. В действующем AGENTS.md и release_publication сохраняются обязательные реальные API37 / 4096 и / 16384: install, upgrade, launch и полный UI suite для точного SHA кандидата. Исторические результаты и успешную сборку нельзя подставлять вместо этой матрицы. Ручной current.json не создавался, publisher и его guards не изменялись.

## Подготовленный серверный транспорт

Изолированная read-only служба analyst-ai-updates.service работает на 127.0.0.1:8081. Root-owned код находится в /opt/analyst-ai-updates; служба использует DynamicUser, ограничения памяти и read-only filesystem.

- GET /client/update-policy читает существующий release contract.
- GET /client/apk/{filename} проверяет реальные байты.
- POST /client/ready всегда возвращает 401; отсутствующая приватная сессия не считается авторизованной.
- Приватная БД и owner state этим приложением не создаются.
- Release root: /srv/analyst-ai-ota/releases, сейчас пустой.
- Проверено после перезапуска: local policy503, ready401, invalid APK404.
- /etc/caddy/Caddyfile.ota-prepared прошёл caddy validate; активный Caddyfile не заменён.
- Публичный HTTPS по-прежнему возвращает maintenance503; private backend ещё не восстановлен.

Следующий обычный выпуск требует настоящей полной Android-матрицы и публикации через проверяющий evidence publisher. Затем нужны переключение подготовленного proxy и внешняя проверка версии, размера, подписи и SHA тех же APK-байтов. Переключение канала делает новую версию обязательной для preview-клиентов; метка «тестовый» сама по себе не меняет этот контракт.
