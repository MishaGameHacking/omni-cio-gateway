## Установить обновление

На присланном владельцем скриншоте установлена **0.12.0-preview / 36**.

1. В Analyst AI нажать **«Повторить проверку»**.
2. Когда сервер покажет **0.12.1-preview**, нажать **«Обновить приложение»**.
3. Разрешить установку из Analyst AI или подтвердить системное окно, если Android попросит.
4. После установки открыть приложение и проверить номер версии.

APK загружается самим приложением с Timeweb. Удалять прежнее приложение или
очищать его данные для обновления не требуется. Старое сообщение «Обновление
установлено. Откройте Analyst AI.» — статус прошлой установки; оно само по себе
не блокирует новую проверку или кнопку обновления.

## Что меняет37

После проверенной policy приложение автоматически начинает обновление,
когда Activity открыта, установка разрешена и нет другой загрузки/установки.
Гейт допускает одну автоматическую попытку на идентичность APK; изменение notes
не создаёт повторную попытку, ошибки и отмена не вызывают бесконечный цикл окон.
Повторная явная попытка доступна пользователю. Сохранённая установочная сессия
восстанавливается до первой проверки версии; регистрация сессии защищена от гонки.

Это **foreground-обновление**. Работа при полностью закрытом приложении не добавлена.
`USER_ACTION_NOT_REQUIRED` используется при подходящих условиях Android;
`STATUS_PENDING_USER_ACTION` обрабатывается. Отсутствие системных подтверждений
на каждом конкретном телефоне не обещается.

Серверные данные и завершённые результаты могут меняться без APK через уже
реализованный live-клиент, когда личный backend и сессия снова работают.
Изменения нативного интерфейса и кода доставляются подписанным APK.
