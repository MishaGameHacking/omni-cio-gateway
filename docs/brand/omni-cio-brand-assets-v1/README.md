# Omni-CIO — Omni Sentinel Core

Статус: **основная композиция утверждена и заморожена**.

Этот пакет содержит production-варианты единого знака Omni-CIO. Форма кольца, положение ядра, направление аналитической траектории, единственная сигнальная точка и cyan → blue → violet палитра не должны изменяться между носителями.

## Главные файлы

- `raster/omni-sentinel-core-1024.png` — канонический мастер 1024×1024 для App Store, PWA и производных экспортов.
- `raster/omni-sentinel-core-{512,256,128}.png` — стандартные полноцветные размеры.
- `raster/omni-sentinel-core-{64,48,32,16}.png` — small-size экспорты: верхняя грань ядра усилена примерно на 8–10%, внешний halo точки уменьшен примерно на 30%.
- `transparent/omni-sentinel-core-color-1024.png` — полноцветный знак на прозрачном фоне.
- `monochrome/omni-sentinel-core-white-1024.png` — белый одноцветный силуэт.
- `monochrome/omni-sentinel-core-dark-1024.png` — тёмный одноцветный силуэт для светлых поверхностей.
- `android/` — foreground/background/monochrome слои и готовые XML-ресурсы adaptive icon.
- `web/` — favicon, Apple Touch Icon и PWA-иконки.
- `qa/` — визуальные проверки реальных размеров, системных масок, светлого фона и Android safe-zone.
- `asset-manifest.json` — размеры, контрольные суммы и технические параметры файлов.

## Android adaptive icon

Слои подготовлены на canvas 432×432 px, что соответствует 108×108 dp при масштабе 4×. Полный alpha-bounds foreground составляет 260×250 px и находится внутри предельной safe-zone 264×264 px (66×66 dp). Внешние 72 px с каждой стороны соответствуют зарезервированным 18 dp.

Для интеграции скопируйте содержимое `android/res/` в Android-модуль приложения. Вариант `mipmap-anydpi-v26` содержит background + foreground; `mipmap-anydpi-v33` дополнительно подключает monochrome layer для themed icons.

Официальная спецификация: [Android adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).

## Результаты QA

1. **32×32:** кольцо, центральное ядро и единственная сигнальная точка различимы; small-size исходник предотвращает слияние ядра с фоном.
2. **16×16:** сохраняется базовый силуэт; это fallback favicon, а не основной размер для детального восприятия.
3. **Monochrome:** знак узнаваем в одном цвете; центральный ромб отличает его от обычного power symbol.
4. **Circle / squircle / rounded square:** важные элементы не обрезаются.
5. **Светлый фон:** полноцветная иконка использует собственную тёмную подложку; для отдельного знака предусмотрен dark monochrome.
6. **Android safe-zone:** alpha-bounds foreground не превышает 66×66 dp.

## Неизменяемые правила

- Никакого текста, монограмм, валют, графиков, стрелок роста, монет, роботов, глаз, щитов, часов и notification badges.
- Только одно кольцо, одно ядро, одна траектория и одна сигнальная точка.
- Нельзя превращать траекторию в стрелку или биржевой график.
- Нельзя добавлять вторую точку, фоновые частицы, сетки, микротекст или декоративный шум.
- В production не встраивать маску или белую рамку в сам мастер: платформы применяют собственные формы.

## Motion language

Композиция остаётся неподвижной. Допустимы только три спокойных состояния: медленный проход света по орбите, едва заметное «дыхание» ядра и один короткий pulse сигнальной точки при новом событии. Анимация не должна менять форму знака или работать постоянно на высокой скорости.
