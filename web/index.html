Проверяем

API-токен проверяется через T-Invest API и сохраняется на сервере только в зашифрованном виде. После сохранения токен больше не отображается.

Подключено

Сейчас достаточно read-only токена. Перед включением реальных сделок его можно заменить на full-access токен, ограниченный конкретным счётом. Transfer-access для OmniCIO не требуется.
