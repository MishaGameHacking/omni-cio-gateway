Без торговых действий

OmniCIO проверяет структуру счёта, доступность данных, блокировки и концентрацию по подтверждённым чтениям T-Invest. На этом этапе система не формирует пакет сделок и не получает торговых полномочий.

Сценарии

Проверка кандидатов

Балансировка только рассчитывает и объясняет сценарии. Она не создаёт торговое поручение, не подтверждает сделки и не вызывает OrdersService. Неполные quote/YTW/liquidity/issuer/tax/cost данные блокируют действие, а не заменяются догадкой.

План

Точный план и решение владельца

Нет активного предложения

Сначала OmniCIO повторно проверяет live evidence и фиксирует конкретную версию сценария: счёт, snapshot, ограничения, before/after, целые лоты, limit price, max spend/min proceeds, комиссии, налоги и срок действия. Только после этого доступно решение по этой exact версии.

Доступно к фиксации

Версии и решения

«Подтвердить план» фиксирует решение владельца только для точной версии плана. Оно не вызывает PostOrder, не выставляет заявку и не включает торговые полномочия. Отклонение требует причины; «отложить» сохраняет дату. При новом snapshot/profile/policy старая версия не считается актуальной.

Проверка исполнения

Теневое и тестовое исполнение

Live выключен

Проверка исполнения использует подтверждённую точную версию плана в Shadow или T-Invest Sandbox. Реальное исполнение подключается отдельно и никогда не включается автоматически: нужен server-side feature gate, точный production-счёт, краткоживущее разрешение и повторное подтверждение пользователя. Пока опубликованные legal-документы v6 описывают режим без реальных поручений, production live остаётся выключен.

Реальное исполнение

Разрешение на реальные сделки

Проверяем gate

Это отдельное разрешение, а не настройка входа или T-Invest. Оно никогда не создаётся автоматически.

Реальное исполнение допускает только подтверждённый deploy_cash, buy-only, limit + Fill-and-Kill, без margin. Укажите собственные лимиты не выше server-side caps и срок не более 24 часов.

Журнал запусков

Состояние запуска

Запуск доступен только у предложения со статусом «подтверждено». Для sandbox подключите именно песочницу T-Invest. Кнопка «Сверить» продолжает state machine по сохранённому request ID; повторная отправка неоднозначной заявки запрещена. Live-торговля появится только на отдельном этапе R7 после новых release gates.

Подключения

Внешние аккаунты и доступ

Здесь подключаются только пользовательские аккаунты и доступы. Публичные рыночные, справочные и исследовательские данные не требуют токена T-Invest.

Т-Банк Инвестиции

T-Invest API

Проверяем

Токен проверяется через T-Invest API и после подключения хранится на сервере только в зашифрованном виде. Сохранённый токен обратно в браузер не возвращается.

Подключено

Для чтения активов и состояния production-счёта достаточно read-доступа. T-Invest Sandbox требует тестовые методы песочницы. Реальное исполнение, если оно отдельно активировано сервером и пользователем, требует write-доступ только к выбранному счёту; transfer-access OmniCIO не требуется.

    Балансировка · R4

    Лимиты распределения

    Не заполнена

    Эти значения задают явные ограничения для сценариев балансировки. OmniCIO не подставляет скрытые проценты концентрации и не получает торговых полномочий. Если policy не заполнена, сценарии сделок не строятся.

    Лимиты инструмента, сектора, эмитента, группы и класса активов — это верхние доли портфеля, а не целевые значения. Бюджет оборота и no-trade band ограничивают лишние перестановки. Налог и haircut — только ваши сценарные допущения: OmniCIO не определяет их автоматически и не выдаёт haircut за вероятность дефолта.

    Ставка налога и оба haircut — явные сценарные допущения пользователя. Кредитный haircut не является вероятностью дефолта и не выдаётся за откалиброванный прогноз. Налоговый процент не определяется автоматически. Лимит участия ограничивает долю подтверждённого среднедневного оборота, которую optimizer вправе считать доступной для выхода. Системные границы текущего R4: новые покупки только RUB-инструментов классов акции/облигации/фонды со статусом риска normal. Резерв, снятия, горизонт ликвидности и разрешение below-grade берутся из версии «Профиль капитала».
