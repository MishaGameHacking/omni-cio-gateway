Решения · этапы R1–R3

Фактический анализ портфеля

Только наблюдение

OmniCIO проверяет структуру счёта, доступность данных, блокировки, концентрацию и накопленные доказательства риска. Система показывает только наблюдения и календарь подтверждённых событий источников: пакет сделок не формируется, торговые полномочия не выдаются.

Подключите счёт T-Invest для анализа.
Незаблокированные рубли — До резерва, налогов, комиссий и активных заявок
Позиций в инструментах — Не равно числу независимых эмитентов
Покрытие секторов — Только среди оценённых рублёвых позиций

Покрытие

Сектора

Неизвестные сектора и состав фондов остаются неизвестными. Страна риска и сектор брокера не заменяют проверку юридического эмитента.

Экспозиции

Доли отдельных инструментов

Инструмент Сектор Оценка Доля

Облигации оцениваются с НКД. Группа связанных компаний и look-through фондов ещё требуют следующих этапов. Кредитный рейтинг не предполагается: пока разрешённый автоматический источник рейтингов не подключён, система явно показывает неполное покрытие.

Доказательства

Источники и время проверки

Время получения данных не является временем последней сделки и само по себе не доказывает свежесть рыночной цены. Недоступный источник отмечается как неполное покрытие, а не заменяется догадкой.

Доказательства риска

Ожидает наблюдения
Ежедневный снимок риска ещё не загружен.

Состояния — объяснимые watch-индикаторы, а не вероятность дефолта. Для банков, страховщиков и девелоперов общие корпоративные пороги не подменяют профильные секторные показатели.

События

Календарь выплат

Здесь показаны даты событий из источника. Они не означают, что деньги уже зачислены на брокерский счёт; фактическое зачисление подтверждается отдельно по операциям счёта.

Т-Банк Инвестиции

T-Invest API

Проверяем

Токен проверяется через T-Invest API и после подключения хранится на сервере только в зашифрованном виде. Сохранённый токен обратно в браузер не возвращается.

Подключено

Для текущего этапа достаточно read-only токена. Transfer-access OmniCIO не требуется.
