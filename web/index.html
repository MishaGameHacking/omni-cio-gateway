Проверяемые расчёты

У каждой цифры есть источник

Биржевые данные и данные счёта приходят через T-Invest. Официальные справочные показатели — из Банка России. Для каждого результата учитываются полнота и время наблюдения.

Если данных недостаточно, система показывает это прямо. Математическая оценка риска не превращается в обещание прибыли.

Контроль остаётся у вас

Сессия подтверждается сервером. Данные одного аккаунта не определяются ссылкой или настройкой в браузере. Сохранение стратегии само по себе не создаёт сделок.
