Уведомление о конфиденциальности и обработке данных

OmniCIO Personal · omnicio.ru · версия 2026-10-01

1. Статус и область действия

OmniCIO Personal — закрытая информационная система для личного использования одним владельцем. Публичная регистрация, предоставление доступа третьим лицам и оказание услуг неопределённому кругу лиц не предусмотрены.

В текущей конфигурации владелец системы и единственный пользователь совпадают. Пункт 1 части 2 статьи 1 Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» исключает из сферы действия закона отношения, возникающие при обработке персональных данных физическим лицом исключительно для личных и семейных нужд, если при этом не нарушаются права субъектов персональных данных. Настоящее уведомление публикуется добровольно для прозрачности технической обработки и не расширяет сферу действия закона.

Если OmniCIO будет открыт для иных лиц, до такого открытия должны быть заново определены правовой режим, документы, основания обработки и обязательные меры соответствия.

2. Какие данные использует система

  • номер мобильного телефона владельца для входа по одноразовому SMS-коду;
  • внутренний ID профиля, технические данные сессии, время входа и события безопасности;
  • защищённые технические идентификаторы запросов, необходимые для ограничения злоупотреблений и диагностики;
  • при подключении T-Invest API — API-токен, выбранный контур, идентификатор и отображаемое имя брокерского счёта;
  • сведения о версии и времени подтверждения применимых правил и уведомлений.

OmniCIO не требует для входа паспортные данные, СНИЛС, ИНН, биометрию, реквизиты банковской карты или сведения о здоровье.

3. Для чего используются данные

Данные используются только для личного входа владельца, поддержания защищённой сессии, предотвращения злоупотреблений, работы и диагностики системы, подключения принадлежащего владельцу брокерского счёта через T-Invest API и безопасного хранения технических учётных данных интеграции.

4. Внешние сервисы

  • Timeweb Cloud — размещение приложения и базы данных в Российской Федерации;
  • SMS Aero — доставка одноразового SMS-кода; сервису передаётся номер телефона и текст служебного сообщения в объёме, необходимом для доставки;
  • T-Bank / T-Invest API — проверка токена и получение сведений о доступных владельцу брокерских счетах только после явного действия владельца в личном аккаунте.

OmniCIO не продаёт данные, не использует их для рекламных рассылок и не предоставляет другим пользователям, поскольку многопользовательский режим отсутствует.

5. Защита данных

Соединение с сайтом выполняется по HTTPS. Номер телефона и T-Invest credential хранятся в зашифрованном виде с раздельными серверными ключами. Одноразовый код и токен сессии не сохраняются в базе данных в открытом виде. Сохранённый T-Invest credential не возвращается браузеру через API и не должен попадать в журналы приложения.

В прикладной базе для части сетевых идентификаторов используются защищённые хеши. Инфраструктурный и сетевой уровни могут технически обрабатывать сетевые метаданные, необходимые для установления соединения, защиты и диагностики.

6. Сроки и удаление

Одноразовый код действителен ограниченное время, установленное серверной конфигурацией. Сессия имеет ограниченный срок и может продлеваться при использовании либо быть немедленно отозвана выходом из аккаунта или защитным действием системы.

T-Invest credential хранится до его замены или удаления владельцем через личный аккаунт. После отключения интеграции сохранённый credential удаляется из прикладной таблицы подключения. Технические журналы и записи безопасности могут сохраняться дольше активной сессии, если это необходимо для диагностики и защиты личной системы.

7. Управление данными владельцем

Владелец может завершить сессию кнопкой «Выйти», отключить T-Invest и удалить сохранённый credential из личного аккаунта, а также отозвать T-Invest token в настройках безопасности T-Bank.

8. Изменения

При изменении режима использования, состава данных, внешних провайдеров или финансового функционала публикуется новая версия документа. Существенное изменение режима с личного на многопользовательский допускается только после отдельной юридической и технической проверки.
