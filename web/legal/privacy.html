2. Область действия

Политика применяется к обработке персональных данных пользователей сайта omnicio.ru и сервиса OmniCIO. Сервис предназначен только для лиц, достигших 18 лет.

3. Какие данные обрабатываются

  • российский мобильный номер телефона, указанный пользователем;
  • публичный девятизначный ID профиля, создаваемый сервисом;
  • технические данные авторизации и защиты сессии: время входа, идентификаторы сессии в защищённом виде, технические сетевые идентификаторы в хешированном виде;
  • сведения о факте, времени и версии принятия юридических документов;
  • события безопасности и аудита, необходимые для защиты сервиса и поддержки пользователя.

OmniCIO не запрашивает паспортные данные, биометрию, банковские реквизиты или сведения о здоровье для обычной регистрации и входа.

4. Цели и правовые основания

Данные обрабатываются для регистрации и входа по одноразовому SMS-коду, ведения аккаунта, защиты от злоупотреблений, поддержки пользователей, исполнения пользовательского соглашения и обязанностей, установленных законодательством Российской Федерации. Когда обработка основана на согласии, пользователь даёт его отдельно от иных подтверждаемых документов.

5. Действия с данными

Оператор может осуществлять сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, передачу в объёме, необходимом для работы привлечённых сервисов, блокирование, удаление и уничтожение персональных данных с использованием автоматизированных средств.

6. Хранение и локализация

Основная база данных пользователей размещается на инфраструктуре Timeweb Cloud в Российской Федерации. Номер телефона хранится в зашифрованном виде; отдельный криптографический индекс используется для поиска и предотвращения дублей. Одноразовые коды в открытом виде в базе данных не хранятся.

Данные хранятся не дольше, чем это необходимо для целей обработки и обязательных сроков, установленных законом. Активная сессия может продлеваться при использовании сервиса; пользователь в любой момент может завершить её кнопкой «Выйти».

7. Привлечённые сервисы

Для работы сервиса могут использоваться Timeweb Cloud как инфраструктурный провайдер и МТС Exolve как поставщик SMS-доставки. Им передаются только данные, необходимые для соответствующей функции. Оператор принимает меры для ограничения доступа и не продаёт персональные данные.

8. Защита

Применяются разграничение доступа, защищённое HTTPS-соединение, шифрование чувствительных данных, хранение секретов вне исходного кода, ограниченные по назначению сессии, журналирование событий безопасности и иные организационные и технические меры.

Для обращения используйте omnicioinfo@gmail.com. Для защиты аккаунта при чувствительных запросах может потребоваться подтверждение владения номером телефона.

При изменении целей или существенных условий обработки публикуется новая версия. Факт принятия применимой версии юридических документов фиксируется сервисом.
