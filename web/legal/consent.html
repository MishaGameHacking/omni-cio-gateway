Согласие на обработку персональных данных

OmniCIO Personal · omnicio.ru · версия 2026-10-02-v3

Это согласие оформляется отдельно от пользовательских правил и политики. Установка отдельной галочки перед началом входа подтверждает, что пользователь ознакомился именно с настоящим документом и добровольно даёт согласие в указанном ниже объёме.

1. Оператор

__OMNICIO_OPERATOR_NAME__, адрес: __OMNICIO_OPERATOR_ADDRESS__, контакт: __OMNICIO_OPERATOR_EMAIL__.

2. Субъект и данные

Согласие относится к пользователю, который инициирует вход через VK ID. Обрабатываются: подтверждённый идентификатор VK ID; внутренний UUID и девятизначный ID профиля; статус и роль аккаунта; технические данные OAuth/PKCE и сессии; защищённый хеш сетевого адреса; версии, дата и время принятия документов; минимальные записи безопасности. При отдельном подключении T-Invest дополнительно обрабатываются сведения о выбранном брокерском счёте и зашифрованный API credential.

3. Цели

Регистрация и вход пользователя, ведение его персонального профиля и сессии, разграничение доступа между пользователями, исполнение правил сервиса, защита от злоупотреблений, диагностика и поддержка; при добровольном подключении T-Invest — проверка credential и работа с данными выбранного пользователем брокерского счёта.

4. Действия с данными

Сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, сопоставление с подтверждённой VK ID identity, передача в минимально необходимом объёме лицам, участвующим в инфраструктуре или запрошенной пользователем интеграции, блокирование, удаление и уничтожение. Обработка преимущественно автоматизированная.

5. Лица и сервисы, участвующие в обработке

Timeweb Cloud используется для размещения приложения и базы данных; VK ID — для внешней аутентификации; T-Bank / T-Invest API — только после отдельного действия пользователя по подключению собственного брокерского API credential. Пароль VK и сохранённый T-Invest credential не возвращаются из этих процессов в открытом виде пользователю через API OmniCIO.

6. Срок действия и отзыв

Согласие действует с момента отдельного подтверждения до достижения целей обработки, удаления аккаунта или отзыва согласия, если обработка не должна или не может продолжаться на ином законном основании. Отозвать согласие можно обращением на __OMNICIO_OPERATOR_EMAIL__. Отзыв обязательной для аутентификации обработки делает дальнейшее использование аккаунта невозможным после завершения необходимых процедур.

7. Фиксация согласия

OmniCIO фиксирует версию настоящего документа, дату и время подтверждения, внутренний ID пользователя и защищённый технический идентификатор запроса. Согласие не объединяется одной галочкой с принятием пользовательских правил или подтверждением ознакомления с политикой.
