Отдельное согласие на обработку данных для входа

OmniCIO Personal · omnicio.ru · версия 2026-10-01-v2

Настоящее подтверждение оформляется отдельно от иных документов. Оно применяется в той мере, в какой соответствующая обработка подпадает под Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных». Для строго личного использования действует оговорка пункта 1 части 2 статьи 1 указанного закона при соблюдении установленных там условий.

1. Данные

Подтверждённый идентификатор VK ID владельца; внутренний ID профиля; технические сведения OAuth/PKCE авторизации, сессии и защиты от злоупотреблений; сведения о факте, времени и версии принятия настоящего документа.

2. Цели

Вход владельца через VK ID, проверка соответствия подтверждённого VK ID заранее настроенному владельцу, поддержание защищённой сессии, защита аккаунта и диагностика работы системы.

3. Действия и способ обработки

Автоматизированные сбор, запись, систематизация, хранение, уточнение, извлечение, использование, передача в минимально необходимом объёме инфраструктурному провайдеру и VK ID для выполнения аутентификации, блокирование и удаление.

4. Получатели, необходимые для входа

Timeweb Cloud обрабатывает данные как инфраструктура размещения. VK ID выполняет внешнюю аутентификацию; пароль VK не передаётся OmniCIO. Подтверждённый идентификатор владельца берётся из ответа VK ID при защищённом обмене авторизационного кода, а access/refresh tokens VK ID не сохраняются после завершения входа. Подключение T-Invest регулируется отдельным подтверждением в личном аккаунте и не является необходимым условием входа.

5. Срок и отзыв

Подтверждение действует, пока используется личный вход OmniCIO, либо до его отзыва, если продолжение обработки не требуется для технической безопасности или не допускается иным применимым основанием. Владелец может прекратить использование системы, завершить сессии и удалить внешние подключения.

6. Фиксация подтверждения

Сервис фиксирует версию документа, время подтверждения и защищённый технический идентификатор запроса. Отдельное оформление согласия соответствует требованию части 1 статьи 9 Федерального закона № 152-ФЗ, действующему с 1 сентября 2025 года.
