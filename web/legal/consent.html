Согласие на обработку персональных данных

OMNICIO · omnicio.ru · версия 2026-10-09-v1.4.0

1. Кому предоставляется согласие

Я даю __OMNICIO_OPERATOR_NAME__, оператору OMNICIO (omnicio.ru), согласие на обработку перечисленных ниже данных для создания и работы моего аккаунта. Контакт оператора: __OMNICIO_OPERATOR_EMAIL__.

Согласие оформляется отдельным действием при регистрации или привязке почты к существующему аккаунту. Общие рыночные страницы доступны без аккаунта.

2. Данные и цели

  • Моя почта и факт её подтверждения, защищённый хеш отдельного пароля OMNICIO, внутренний идентификатор, сведения о сессиях и согласиях — для входа, проверки владения почтой, восстановления и защиты аккаунта.
  • Временные записи проверочных кодов, зашифрованная очередь служебных писем и производные значения для ограничения частоты — для безопасной доставки и проверки подтверждений.
  • При отдельном подключении T-Invest: зашифрованный токен только для чтения, технический идентификатор счёта, текущие позиции, количество и блокировки инструментов, денежные остатки и их снимки — для анализа текущего состава моего портфеля с выбранной стратегией.
  • Добровольно сохраняемые настройки, избранное, параметры стратегии, цели, сообщения и выбранный контекст помощника, каналы уведомлений и данные оплаты плана — для соответствующих выбранных функций.

Пароль от моей почты не требуется. Исходный пароль OMNICIO не сохраняется. Сервис не запрашивает брокерский профиль, историю покупок, пополнений, переводов или других операций. Пользовательский токен не используется для общего рыночного сбора, торговли, отмены заявок или перевода денег.

Моя почта и связанный с аккаунтом портфель не становятся публичными. Данные общего рынка обрабатываются отдельно и не раскрывают мой портфель другим пользователям.

3. Действия и подключения

Согласие охватывает сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, необходимую передачу поставщикам выбранных функций, блокирование и удаление данных, включая автоматизированную обработку. Для размещения используется Timeweb Cloud; для проверки почты — почтовая служба, настроенная оператором; для моего подключённого счёта — API T-Invest. Подключение внешней модели, уведомлений или оплаты имеет отдельную функциональную цель, описанную в политике и интерфейсе.

Я могу управлять действующими сессиями, отключить портфель, выключить уведомления и удалить аккаунт. При восстановлении пароля ранее выданные сессии отзываются. Подтверждение почты доказывает доступ к указанному ящику и не заменяет проверку паспортной личности.

4. Срок и отзыв

Согласие действует с момента подтверждения до удаления аккаунта или отзыва, с учётом сроков, необходимых для выполнения соответствующей цели и применимых обязанностей. Для отзыва можно удалить аккаунт либо обратиться по адресу оператора. Отзыв не отменяет обработку, которую закон допускает продолжать на отдельном основании.
