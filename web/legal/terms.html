Правила личного использования OmniCIO Personal

OmniCIO Personal · omnicio.ru · версия 2026-10-01-v2

1. Закрытый характер системы

OmniCIO Personal предназначен исключительно для личного использования владельцем. Публичная регистрация, предоставление аккаунтов третьим лицам, продажа доступа и оказание платных услуг через текущую версию сайта не предусмотрены.

Настоящие правила не являются публичной офертой по смыслу статьи 437 Гражданского кодекса Российской Федерации и не выражают намерение заключать договор с любым лицом, которое откроет сайт.

2. Доступ

Вход разрешён только через заранее разрешённый VK ID владельца. Сервер сравнивает подтверждённый VK ID с настройкой OWNER и не создаёт сессию для другого аккаунта. Сессионные cookie и другие средства доступа нельзя передавать третьим лицам. При подозрении на компрометацию доступ может быть отозван, а ключи и токены должны быть заменены.

3. Возраст

Система рассчитана на совершеннолетнего владельца. В интерфейсе входа отдельно подтверждается достижение 18-летнего возраста.

4. Подключение T-Invest API

Разрешено подключать только собственный T-Invest token владельца и только к брокерскому счёту, которым владелец вправе распоряжаться. Token передаётся непосредственно T-Invest API для проверки прав и затем хранится в OmniCIO только в зашифрованном виде.

Для мониторинга рекомендуется использовать минимально необходимые права. Full-access должен применяться только когда функциональность реальных торговых поручений отдельно реализована, протестирована и включена владельцем. Transfer-access для текущей архитектуры не требуется.

T-Bank и T-Invest являются внешними сервисами. OmniCIO не является официальным продуктом, представительством или частью T-Bank.

5. Финансовый функционал и риски

Текущая версия OmniCIO предоставляет личную техническую интеграцию и инструменты анализа. Она не оказывает инвестиционные консультационные услуги третьим лицам и не предназначена для распространения индивидуальных инвестиционных рекомендаций неопределённому кругу пользователей.

Любые будущие расчёты, сигналы, оценки или предложения действий предназначены только владельцу как вспомогательная информация для собственных решений. Рыночные операции связаны с риском убытков. До включения реального исполнения сделок должен использоваться отдельный детерминированный контур проверки лимитов и рисков; автоматическое исполнение не должно включаться только на основании текста, сформированного AI/LLM.

6. Ограничение публичного использования T-Invest API

OmniCIO не должен превращаться в публичный сервис на базе T-Invest API без отдельного письменного разрешения или иной допустимой модели взаимодействия с правообладателем API. Доступ к данным T-Invest не должен ретранслироваться другим пользователям.

7. Данные и безопасность

Правила обращения с данными описаны в Уведомлении о конфиденциальности. Отдельное подтверждение обработки данных для входа размещено в соответствующем документе.

API tokens, ключи, OAuth/PKCE секреты и иные чувствительные данные нельзя публиковать, отправлять в чаты, размещать в исходном коде или сохранять в скриншотах.

8. Законодательство о защите прав потребителей

Текущая single-owner модель не предусматривает продавца или исполнителя, оказывающего товары, работы или услуги иному потребителю. Поэтому настоящие правила не содержат условий публичного потребительского договора. Если в будущем появятся сторонние пользователи, платный доступ или оказание услуг, до запуска должны быть отдельно проверены обязательные требования Закона РФ № 2300-1 «О защите прав потребителей» и иных применимых норм.

Ничто в настоящих правилах не направлено на ограничение прав, которые по императивным нормам закона не могут быть ограничены соглашением, если соответствующие правоотношения возникнут в будущем.

9. Изменение режима использования

Добавление второго пользователя, публичной регистрации, платных услуг, передачи чужих персональных данных, публичных инвестиционных рекомендаций или исполнения операций в интересах иных лиц требует предварительного пересмотра правовой модели и настоящих правил.
