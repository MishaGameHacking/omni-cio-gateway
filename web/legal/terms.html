Пользовательские правила OMNICIO

OMNICIO · omnicio.ru · версия 2026-10-07-v1.3.0

1. Сервис и доступ

OMNICIO — персональный веб-интерфейс для просмотра собственных инвестиционных данных и технической аналитики. Оператор: __OMNICIO_OPERATOR_NAME__, контакт: __OMNICIO_OPERATOR_EMAIL__.

Архитектура поддерживает несколько изолированных пользователей. Новые аккаунты создаются только когда серверная регистрация явно включена. Текущий временный live-test лимит — два пользовательских аккаунта. Слоты не закреплены за заранее указанными идентификаторами провайдеров: их получают первые два пользователя, которые успешно проходят T-ID или VK ID и принимают актуальные документы. После заполнения лимита новые аккаунты не создаются. Увеличение лимита выполняется только серверной конфигурацией после технической и юридической проверки.

2. Учётная запись и полномочия

Вход выполняется через T-ID или VK ID. Пользователь обязан использовать собственную учётную запись выбранного провайдера и не передавать сессионные cookie третьим лицам. Публичный профиль создаётся с ролью user. Эта роль не предоставляет административного доступа к серверу, базе данных, настройкам других пользователей или инфраструктуре.

При подозрении на компрометацию сессии оператор вправе отозвать её, временно заблокировать аккаунт и потребовать повторной авторизации.

3. Возраст

Текущая версия предназначена для совершеннолетних пользователей. Перед входом пользователь отдельно подтверждает достижение 18-летнего возраста. Если это подтверждение не дано, аккаунт не создаётся.

4. T-Invest

Пользователь вправе подключать только свой API credential T-Invest и только брокерский счёт, которым он вправе распоряжаться. Credential проверяется через T-Invest API и хранится на сервере в зашифрованном виде; сохранённое значение обратно в браузер не выдаётся.

Для текущего функционала следует использовать минимально необходимые права. OMNICIO не требует transfer-access. Текущая версия может ежедневно получать read-only данные выбранного счёта, сохранять доказательные снимки портфеля и внутренние наблюдения по истории операций для сверки. По наблюдениям операций рассчитываются инвестиционный результат и фактически полученные выплаты; в личных событиях могут отображаться относящиеся к счёту изменения. История считается полной только при подтверждённом покрытии источника. Реальные торговые поручения не исполняются текущей версией системы.

T-Bank и T-Invest являются внешними сервисами. OMNICIO не является официальным продуктом, представительством или подразделением T-Bank.

5. Информация о рынке и инвестиционные риски

Отображаемые котировки, показатели портфеля, структура активов, результаты поиска инструментов и технические расчёты носят информационный характер. Пользователь может сохранить версионные ограничения капитала и риска; сами по себе они не являются поручением на сделку и не предоставляют OMNICIO торговых полномочий. Текущая версия не исполняет сделки и не принимает решения о совершении сделок за пользователя.

Операции с финансовыми инструментами связаны с риском убытков. Пользователь самостоятельно принимает решения и проверяет сведения у брокера и иных первичных источников.

Готовые стратегии являются настраиваемыми аналитическими подходами. Историческое исследование использует отдельные периоды выбора и проверки, указанные пользователем комиссии, проскальзывание и капитал. Ценовой результат без дивидендов и корпоративных действий обозначается отдельно от полной доходности. Недостаток истории или данных не заменяется обещанной вероятностью успеха.

Цели могут отслеживаться по доле подключённого портфеля, фактическим выплатам или введённой пользователем сумме. Прогресс не является гарантией достижения цели. Изменения настроек проверяются сервером; при конфликте версий требуется загрузить актуальное состояние.

ИИ, когда он подключён, помогает объяснять данные и может ошибаться. Ответ не создаёт сделку и не изменяет настройки. Контекст портфеля отправляется только по выбору пользователя; результаты следует сверять с показанными источниками и расчётами.

6. Данные и конфиденциальность

Правила обработки персональных данных описаны в Политике обработки персональных данных. Отдельное согласие размещено в Согласии на обработку персональных данных. Один пользователь не получает доступ к данным другого пользователя; browser-provided ID не является источником полномочий.

7. Самостоятельное удаление аккаунта

Пользователь может удалить свой аккаунт в разделе «Настройки». Перед выполнением операции OMNICIO требует повторно ввести текущий девятизначный ID профиля и подтвердить необратимость удаления. После подтверждения профиль, привязки T-ID и VK ID, пользовательские сессии, связанные записи согласий, цели, настройки, события, избранное, стратегии, диалоги и память ИИ, подписки и очередь уведомлений, сохранённое подключение T-Invest удаляются; текущая сессия завершается, а занятый регистрационный слот освобождается.

Удаление аккаунта необратимо. Если регистрация остаётся открытой и есть свободный слот, тот же T-ID или VK ID впоследствии может создать новый аккаунт, который будет новым профилем и не восстанавливает данные удалённого аккаунта.

8. Допустимое использование

Запрещены попытки обхода аутентификации, получения доступа к чужим данным, эксплуатации уязвимостей, перегрузки сервиса, публикации секретов или использования чужих T-Invest credentials. Обнаруженную уязвимость следует сообщить оператору по адресу __OMNICIO_OPERATOR_EMAIL__, не извлекая чужие данные и не причиняя ущерб.

9. Доступность и изменения

Сервис может временно быть недоступен из-за технических работ, отказа внешнего провайдера или мер безопасности. Существенные изменения правил, обработки персональных данных или финансового функционала публикуются новой версией. Если закон требует нового согласия, пользователь должен подтвердить новую версию до продолжения соответствующей обработки.

Установка веб-приложения и системные уведомления необязательны. Установка сама по себе не даёт разрешения присылать сообщения: уведомления включаются отдельным действием пользователя с разрешением браузера. Поддержка установки и фоновой доставки зависит от браузера, операционной системы, сети и настроек устройства. OMNICIO использует Web Push, без SMS и обязательного ввода контактных данных.

Принятие сообщения службой доставки не подтверждает его показ или прочтение на устройстве. Уведомления содержат общее сообщение о событии; подробности показываются в текущем аккаунте после проверки сессии. Выход прекращает новые отправки по привязке этой сессии. Отключение уведомлений не препятствует просмотру событий на сайте; уже принятое внешней службой сообщение нельзя гарантированно отозвать.

10. Права пользователя

Ничто в настоящих правилах не ограничивает права пользователя, которые не могут быть ограничены соглашением по применимому законодательству. Если конкретные отношения подпадают под законодательство о защите прав потребителей или иные императивные нормы, такие нормы применяются независимо от формулировок настоящих правил.
