# Политика безопасности

Omni-CIO Gateway работает с финансовыми данными и должен оставаться строго read-only.

## Сообщение об уязвимости

Не публикуйте токены, ключи, номера счетов, содержимое брокерских отчётов, Authorization headers или персональные данные в Issues и Pull Request. Используйте приватный канал владельца репозитория.

В сообщении укажите без секретов:

- затронутый commit или release;
- endpoint или модуль;
- воспроизводимые шаги на фиктивных данных;
- ожидаемое и фактическое поведение;
- возможное влияние;
- безопасный вариант исправления.

## Критические инварианты

- `trading_methods=false`.
- Пользовательские Actions используют только `GET`.
- Нет создания, отправки, замены, отмены заявок и стоп-заявок.
- `app:app` остаётся стабильным production entrypoint.
- Секреты поступают только через переменные окружения.
- Ответы маскируют номер счёта.
- Ошибки очищаются от секретов перед выводом.

## Запрещённые данные в Git

- `TINVEST_TOKEN`;
- `GATEWAY_API_KEY`;
- полный ID брокерского счёта;
- реальные HTML/PDF/JSON брокерские отчёты;
- логи с чувствительными значениями;
- приватные ключи и сертификаты пользователя.

## Проверка перед merge

Regression Shield должен подтвердить отсутствие торговых operationId и mutating routes, Bearer-защиту Actions, валидность OpenAPI и совпадение версии runtime.
